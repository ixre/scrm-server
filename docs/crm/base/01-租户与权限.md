# 租户与权限

## 目的
多租户 SaaS 隔离 + 员工/角色权限控制。

## 入口
- 工作台 → 系统设置 → 租户管理（仅超管）
- 工作台 → 系统设置 → 角色权限

## 数据模型

### Tenant（租户）

`models/tenant.go`：

| 字段 | 说明 |
|------|------|
| `id` | 租户 ID |
| `name` | 公司名 |
| `code` | 租户编码（唯一） |
| `status` | active / disabled / expired |
| `expire_at` | 到期时间（SaaS 订阅） |
| `plan` | 套餐：free / pro / enterprise |

### RBAC

- 用户：员工账号（Staff）
- 角色：Role（admin / sales_manager / sales / cs）
- 权限：Permission（菜单 + 操作）
- 资源：Menu / Button / DataScope

## 操作步骤

### 1. 创建租户（超管）

**接口**：`tenant.Create`

```json
{
  "name": "Acme 公司",
  "code": "acme",
  "plan": "pro",
  "expire_at": "2027-08-18"
}
```

### 2. 角色管理

**接口**：`rbac.CreateRole / ListRoles`

```json
{
  "name": "销售经理",
  "code": "sales_manager",
  "menu_ids": ["customer", "opportunity", "order"],
  "data_scope": "department"  // 部门级数据权限
}
```

**预设角色**：

| 角色 | 权限 |
|------|------|
| 超管 | 全部 |
| 销售总监 | 全部业务 + 部门数据 |
| 销售经理 | 业务 + 团队数据 |
| 销售 | 仅自己的客户 |
| 客服 | 仅客户沟通 + 工单 |
| 财务 | 仅财务模块 |

### 3. 员工授权

**接口**：`rbac.AssignRole(staffID, roleID)`

### 4. 数据权限

| scope | 含义 |
|-------|------|
| `all` | 全部数据（超管） |
| `department` | 本部门及下级 |
| `self` | 仅自己 |

## 权限校验中间件

```go
// middleware/rbac.go
func RequirePermission(perm string) gin.HandlerFunc {
    return func(c *gin.Context) {
        if !HasPermission(c, perm) {
            c.AbortWithStatus(403)
        }
    }
}
```

## 多租户隔离

**自动注入**：`tenant_id` 通过 JWT 自动注入到 ctx，业务 SQL 自动加 WHERE tenant_id=?：

```go
// db/tenant.go
func WithTenant(ctx context.Context, q *query.Query) *query.Query {
    tenantID := ctx.GetString("tenant_id")
    return q.Where("tenant_id = ?", tenantID)
}
```

## 注意事项

- **越权防护**：所有 SQL 必须带 `tenant_id`，**当前已通过中间件自动注入**。
- **角色变更**：员工调岗时**及时更新角色**。
- **数据权限**：跨部门数据查询需用 `data_scope=department`。

## 当前限制（**产品补强点**）

- 无字段级权限（同一菜单下不同字段可见性不同）。
- 无 ABAC（基于属性的权限）。
- 无租户间数据隔离测试。
