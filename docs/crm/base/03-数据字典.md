# 数据字典

> **实现状态：部分实现**

## 目的
统一管理状态、类型、分类等枚举值，避免代码硬编码。

## 入口
- 无独立菜单（数据字典功能未完整实现）

## 当前实现

当前只实现了 `crm_dict.AddWay` 接口，用于下发各渠道的客户添加/承接方式字典（`crm_customer.add_way` 字段展示）。

### 已实现接口

**接口**：`crm_dict.AddWay`

```json
// 请求：无参数
// 返回：constants.AddWayByChannel —— 按渠道组织的添加方式字典
```

该接口返回各渠道（企微/小红书/公众号/抖音等）的添加/承接方式枚举，供前端展示 `CrmCustomer.add_way` 字段时使用，无需前端硬编码。

## 注意事项

- **字典项不可删除**：已使用的 value 应标记 `disabled=true`，避免历史数据失效。
- **新增字典项**：通过后台添加，**不需要发版**。
- **跨租户**：同一字典 code 在不同租户**可独立维护**。

## 当前限制（**产品补强点**）

- 数据字典功能**未完整实现**，当前仅有 `crm_dict.AddWay` 下发渠道添加方式。
- 无 Dict / DictItem 模型与 CRUD 接口。
- 无字典版本控制（修改字典无审计）。
- 无字典导入导出。
- 无业务字段绑定（如订单状态字段绑定 order_status 字典）。
