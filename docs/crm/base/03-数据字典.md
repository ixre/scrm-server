# 数据字典

## 目的
统一管理状态、类型、分类等枚举值，避免代码硬编码。

## 入口
- 工作台 → 系统设置 → 数据字典

## 数据模型

### Dict（字典）

| 字段 | 说明 |
|------|------|
| `id` | 字典 ID |
| `code` | 字典编码（如 `customer_status`） |
| `name` | 字典名 |
| `items` | 字典项列表 |

### DictItem（字典项）

| 字段 | 说明 |
|------|------|
| `dict_id` | 字典 ID |
| `value` | 值 |
| `label` | 显示名 |
| `sort` | 排序 |
| `color` | 颜色（前端用） |
| `is_default` | 是否默认 |

## 操作步骤

### 1. 创建字典

**接口**：`dict.Create`

```json
{
  "code": "customer_status",
  "name": "客户状态",
  "items": [
    {"value": "new", "label": "新客户", "color": "blue", "sort": 1},
    {"value": "active", "label": "活跃", "color": "green", "sort": 2},
    {"value": "lost", "label": "流失", "color": "red", "sort": 3}
  ]
}
```

### 2. 查询字典

**接口**：`dict.GetByCode(code)`

```go
返回：[{value, label, color, sort}, ...]
```

### 3. 修改字典项

**接口**：`dict.UpdateItem`

## 系统预设字典

## 业务使用

```go
// 在代码中：
statuses := dict.GetByCode("customer_status")
// 返回 [{value:"new", label:"新客户"}, ...]
```

前端展示：

```tsx
<Select>
  {statuses.map(s => <Option value={s.value}>{s.label}</Option>)}
</Select>
```

## 注意事项

- **字典项不可删除**：已使用的 value 应标记 `disabled=true`，避免历史数据失效。
- **新增字典项**：通过��台添加，**不需要发版**。
- **跨租户**：同一字典 code 在不同租户**可独立维护**（**当前实现是租户级**）。

## 当前限制（**产品补强点**）

- 无字典版本控制（修改字典无审计）。
- 无字典导入导出。
- 无业务字段绑定（如订单状态字段绑定 order_status 字典）。
