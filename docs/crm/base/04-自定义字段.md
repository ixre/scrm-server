# 自定义字段

## 目的
客户/订单等模型支持租户自定义字段，适配各行业需求。

## 入口
- 企业管理 → 系统设置 → 字段设置

## 数据模型

### CrmFieldDef（字段定义）

`models/crm.go`：动态字段定义，按 `tenant_id` 分区。

| 字段 | 类型 | 说明 |
|------|------|------|
| `tenant_id` | string | 归属租户 ID |
| `entity_type` | string | 实体类型（customer / lead / opportunity / order） |
| `field_key` | string | 字段标识 |
| `field_label` | string | 字段名称 |
| `field_type` | string | 字段类型（text/number/select/multiselect/date/datetime/textarea/file） |
| `options` | StringArrayField | 选项列表（select/multiselect 用，jsonb） |
| `is_required` | bool | 是否必填 |
| `is_searchable` | bool | 是否可搜索 |
| `default_value` | string | 默认值 |
| `sort` | int | 排序 |
| `status` | string | active / disabled |

### CrmFieldValue（字段值）

`models/crm.go`：动态字段值，按 `(tenant_id, entity_type, entity_id, field_key)` 存储。

| 字段 | 类型 | 说明 |
|------|------|------|
| `tenant_id` | string | 归属租户 ID |
| `entity_type` | string | 实体类型 |
| `entity_id` | string | 实体 ID |
| `field_key` | string | 字段标识 |
| `value` | text | 字段值 |

### CrmScene（列表场景）

`models/crm.go`：列表场景（自定义筛选条件集合），按 `tenant_id` 分区。

| 字段 | 说明 |
|------|------|
| `tenant_id` | 归属租户 ID |
| `user_id` | 归属用户（0=租户级） |
| `entity_type` | 实体类型（customer/lead/opportunity） |
| `name` | 场景名称 |
| `conditions` | 筛选条件 JSON（jsonb） |
| `is_default` | 是否默认场景 |
| `is_shared` | 是否共享给团队 |
| `sort` | 排序 |

**接口**：`crm_scene.List / Create / Update / Delete / SetDefault / DragSort`

## 操作步骤

### 1. 创建自定义字段

**接口**：`crm_field_def.Create`

```json
{
  "entity_type": "customer",
  "field_key": "industry",
  "field_label": "所属行业",
  "field_type": "select",
  "options": ["电商", "教育", "金融", "医疗"],
  "is_required": true,
  "is_searchable": true,
  "sort": 1
}
```

### 2. 客户详情动态渲染

前端调用 `crm_field_def.List`（参数 `entity_type=customer`）获取字段列表 + 每个客户的 `crm_field_value.Get`（参数 `entity_type/entity_id`）返回字段值：

```json
{
  "id": "100",
  "name": "张三",
  "mobile": "13800138000",
  "custom_fields": {
    "industry": "电商",
    "company_size": "100-500"
  }
}
```

### 3. 客户筛选（is_searchable=true）

列表筛选接口支持按自定义字段过滤：

```json
{
  "filters": [
    {"field": "industry", "op": "eq", "value": "电商"}
  ]
}
```

### 4. 列表展示

列表页可显示任意 `is_searchable=true` 的自定义字段。

## 支持的字段类型

| field_type | 控件 | 存储 |
|------------|------|------|
| text | 单行输入 | string |
| textarea | 多行输入 | text |
| number | 数字输入 | float |
| date | 日期选择 | date |
| datetime | 日期时间选择 | datetime |
| select | 下拉单选 | string |
| multiselect | 下拉多选 | JSON array |
| file | 文件上传 | string (URL) |

## 实现方式

**当前方案**：独立 `crm_field_value` 表，按 `(entity_type, entity_id, field_key)` 存储，支持 upsert。

**优点**：
- 灵活加字段，无需改表
- 租户级隔离（通过 `models.TenantScope`）
- 字段配置变更不影响历史数据

**缺点**：
- 查询性能略差（需关联）
- 不支持强类型索引

## 注意事项

- **字段名唯一**：同一 `entity_type` 内 `field_key` 唯一。
- **删除限制**：已使用字段不可删除，仅可禁用（`status=disabled`）。
- **必填校验**：保存时校验 `is_required=true` 的字段。
- **类型变更**：修改字段 `field_type` 可能破坏历史数据，**建议禁用后新建**。

## 当前限制（**产品补强点**）

- 无公式字段（如 `total = price * quantity`）。
- 无级联字段。
- 无字段权限（不同角色看到的字段不同）。
