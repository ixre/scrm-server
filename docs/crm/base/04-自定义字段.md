# 自定义字段

## 目的
客户/订单等模型支持租户自定义字段，适配各行业需求。

## 入口
- 工作台 → 系统设置 → 自定义字段

## 数据模型

### CustomField（自定义字段）

| 字段 | 说明 |
|------|------|
| `entity` | 实体（customer / order / opportunity） |
| `field_name` | 字段名（英文） |
| `label` | 显示名 |
| `type` | text / number / date / select / multi_select / textarea |
| `required` | 是否必填 |
| `options` | 选项（select 类型） |
| `default_value` | 默认值 |
| `sort` | 排序 |
| `is_filter` | 是否可用于筛选 |

### CustomFieldValue（字段值）

| 字段 | 说明 |
|------|------|
| `entity_id` | 业务对象 ID |
| `field_id` | 自定义字段 ID |
| `value` | 值 |

## 操作步骤

### 1. 创建自定义字段

**接口**：`custom_field.Create`

```json
{
  "entity": "customer",
  "field_name": "industry",
  "label": "所属行业",
  "type": "select",
  "options": ["电商", "教育", "金融", "医疗"],
  "required": true,
  "is_filter": true,
  "sort": 1
}
```

### 2. 客户详情动态渲染

前端调用 `GET /custom_field/list?entity=customer` 获取字段列表 + 每个客户的 `GET /customer/{id}` 返回 `custom_fields` map：

```json
{
  "id": "100",
  "name": "张三",
  "mobile": "13800138000",
  "custom_fields": {
    "industry": "电商",
    "company_size": "100-500"
  }
}
```

### 3. 客户筛选（is_filter=true）

列表筛选接口支持按自定义字段过滤：

```json
{
  "filters": [
    {"field": "industry", "op": "eq", "value": "电商"}
  ]
}
```

### 4. 列表展示

列表页可显示任意 `is_filter=true` 的自定义字段。

## 支持的字段类型

| type | 控件 | 存储 |
|------|------|------|
| text | 单行输入 | string |
| textarea | 多行输入 | text |
| number | 数字输入 | float |
| date | 日期选择 | date |
| select | 下拉单选 | string |
| multi_select | 下拉多选 | JSON array |
| checkbox | 复选 | bool |
| file | 文件上传 | string (URL) |

## 实现方式

**当前方案**：独立 `custom_field_value` 表，按 (entity_id, field_id) 存储。

**优点**：
- 灵活加字段，无需改表
- 租户级隔离
- 字段配置变更不影响历史数据

**缺点**：
- 查询性能略差（需关联）
- 不支持强类型索引

## 注意事项

- **字段名唯一**：同一 `entity` 内 `field_name` 唯一。
- **删除限制**：已使用字段不可删除，仅可禁用。
- **必填校验**：保存时校验 `required=true` 的字段。
- **类型变更**：修改字段 type 可能破坏历史数据，**建议禁用后新建**。

## 当前限制（**产品补强点**）

- 无公式字段（如 `total = price * quantity`）。
- 无级联字段。
- 无字段权限（不同角色看到的字段不同）。
