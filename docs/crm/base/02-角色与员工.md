# 角色与员工

## 目的
管理员工账号、组织架构、角色权限。

## 入口
- 工作台 → 系统设置 → 员工管理
- 工作台 → 系统设置 → 组织架构

## 数据模型

### Staff（员工）

| 字段 | 说明 |
|------|------|
| `id` | 员工 ID |
| `name` | 姓名 |
| `mobile` | 手机号（登录账号） |
| `email` | 邮箱 |
| `wecom_userid` | 企微 userid |
| `department_id` | 部门 |
| `role_ids` | 角色列表 |
| `status` | active / disabled / resigned |
| `joined_at` | 入职时间 |
| `leave_at` | 离职时间 |

### Department（部门）

| 字段 | 说明 |
|------|------|
| `id` | 部门 ID |
| `name` | 部门名 |
| `parent_id` | 上级部门 |
| `manager_id` | 部门负责人 |
| `sort` | 排序 |

### Role（角色）

| 字段 | 说明 |
|------|------|
| `id` | 角色 ID |
| `name` | 角色名 |
| `code` | 角色编码 |
| `menu_ids` | 菜单权限 |
| `button_ids` | 按钮权限 |
| `data_scope` | 数据权限 |

## 操作步骤

### 1. 创建部门

**接口**：`staff.CreateDepartment`

```json
{
  "name": "华东销售部",
  "parent_id": "销售中心",
  "manager_id": "2001"
}
```

### 2. 创建员工

**接口**：`staff.Create`

```json
{
  "name": "张三",
  "mobile": "13800138000",
  "email": "zhangsan@example.com",
  "department_id": "1001",
  "role_ids": ["sales"]
}
```

### 3. 调岗 / 离职

**接口**：`staff.UpdateStatus / TransferDepartment`

```go
员工离职流程：
1. staff.UpdateStatus(status=resigned)
2. 触发 CrmCustomerTransfer：客户/群/工单转交
3. 禁用账号登录
4. 触发企微 transfer_external_user
```

### 4. 组织架构树

**接口**：`staff.GetOrgTree`

返回树形结构：

```
公司
├── 销售中心
│   ├── 华东销售部
│   │   ├── 张三
│   │   └── 李四
│   └── 华南销售部
└── 客服部
```

## 角色预设

| 角色 | 默认权限 |
|------|----------|
| 超管 | 全部菜单 + 全部数据 |
| 销售总监 | 业务菜单 + 部门数据 |
| 销售经理 | 业务菜单 + 团队数据 |
| 销售 | 业务菜单 + 个人数据 |
| 客服 | 客户+工单 + 个人数据 |
| 财务 | 财务菜单 + 全部财务数据 |

## 离职继承

详见 [risk/02-客户继承.md](../risk/02-客户继承.md)。

## 注意事项

- **手机号唯一**：同一租户内员工手机号唯一。
- **角色多对多**：一个员工可有多个角色（权限并集）。
- **离职流程**：**必须执行客户继承**，否则客户丢失。

## 当前限制（**产品补强点**）

- 无岗位体系（职位等级）。
- 无兼职/外包员工模型。
- 无员工操作审计。
