# 角色与员工

## 目的
管理员工账号、组织架构、角色权限。系统存在两套员工体系：企微域 Staff（企微同步）与 CRM 原生域 User（本地账号）。

## 入口
- 企业管理 → 员工管理
- 企业管理 → 权限管理

## 数据模型

### Staff（企微员工）

`models/staff.go`：企微同步的员工模型，主键为本地 ID，按 `ext_corp_id` 分区。

| 字段 | 说明 |
|------|------|
| `ext_corp_id` | 外部企业 ID（企微 corp_id） |
| `ext_id` | 外部员工 ID（企微 userid，企业内唯一） |
| `role_id` | 角色 ID |
| `role_type` | 角色类型：superAdmin / admin / departmentAdmin / staff |
| `name` | 员工名 |
| `mobile` | 手机号 |
| `email` | 邮箱 |
| `gender` | 性别（0-未知 1-男 2-女） |
| `status` | 激活状态：1-已激活 2-已禁用 4-未激活 5-退出企业 |
| `enable` | 启用状态：0-禁用 1-启用 |
| `avatar_url` | 头像 URL |
| `dept_ids` | 所属部门 ID 数组（jsonb） |
| `welcome_msg_id` | 欢迎语 ID |
| `is_authorized` | 是否授权：1-是 2-否 |
| `enable_msg_arch` | 会话存档：1-是 2-否 |
| `external_position` | 职务信息 |
| `signature` | 微信返回内容签名 |

### User（CRM 原生用户）

`models/crm.go`：CRM 原生域独立的本地用户（销售/员工账号），取代企微 staff 作为鉴权与归属单元。按 `tenant_id` 分区，主键为本地 ID。

| 字段 | 说明 |
|------|------|
| `tenant_id` | 归属租户 ID |
| `username` | 登录名（租户内唯一） |
| `password` | 登录密码（哈希） |
| `name` | 显示名 |
| `mobile` | 手机号 |
| `email` | 邮箱 |
| `role_id` | 角色 ID（引用 CrmRole） |
| `position` | 职位 |
| `department_id` | 部门 ID |
| `avatar` | 头像 |
| `status` | 1-启用 2-停用 |
| `last_login_at` | 最后登录时间 |

### ChannelLink（渠道映射）

`models/crm.go`：把本地实体（租户/用户/客户）与外部渠道 ID（如企微 ext id）关联。企微 external id 从"主键"降级为"渠道外部键"。

| 字段 | 说明 |
|------|------|
| `tenant_id` | 本地租户 ID |
| `channel` | 渠道标识（如 wecom） |
| `entity_type` | 实体类型（tenant/user/customer） |
| `entity_id` | 本地实体主键 |
| `ext_id` | 渠道外部 ID（如企微 external_userid） |
| `ext_corp_id` | 渠道外部企业 ID（如企微 corp_id） |

### Department（部门）

`models/department.go`：

| 字段 | 说明 |
|------|------|
| `tenant_id` | 租户 ID |
| `ext_corp_id` | 外部企业 ID |
| `ext_id` | 企微部门 ID |
| `name` | 部门名称 |
| `ext_parent_id` | 上级部门 ID（根部门为 1） |
| `order` | 在父部门中的次序值 |
| `welcome_msg_id` | 部门使用的欢迎语 |
| `staff_num` | 成员数量 |

### Role（企微域角色）

`models/role.go`：企微域角色，按 `ext_corp_id` 分区。

| 字段 | 说明 |
|------|------|
| `ext_corp_id` | 外部企业 ID |
| `name` | 角色名称 |
| `description` | 角色描述 |
| `type` | 角色类型：Admin / DepartmentAdmin / Staff |
| `sort_weight` | 排序权重 |
| `is_default` | 是否默认角色（1-是 2-否） |
| `permission_ids` | 权限标识数组（jsonb） |

### CrmRole（CRM 原生角色）

`models/crm.go`：CRM 原生权限模型，按 `tenant_id` 分区。详见 [01-租户与权限.md](01-租户与权限.md)。

## 操作步骤

### 1. 创建部门

**接口**：`department.Query / Get`（标注：当前仅支持查询，部门由企微同步创建，无独立创建接口）

### 2. 创建员工

**企微域**：员工由企微同步（`staff.Sync`），无独立创建接口。

**CRM 原生域**：`crm_user.Create`（创建本地 User 账号）

```json
{
  "username": "zhangsan",
  "name": "张三",
  "mobile": "13800138000",
  "role_id": "xxx",
  "department_id": "1001"
}
```

### 3. 调岗 / 离职

**接口**：`staff.Enable`（启用/禁用企微员工）

> 标注：`staff.UpdateStatus / TransferDepartment` 未实现。员工离职流程中的客户继承详见 [risk/02-客户继承.md](../risk/02-客户继承.md)。

CRM 原生用户状态更新走 `crm_user.Update`（设置 `status`）。

### 4. 组织架构树

**接口**：`department.Get`（按部门 ID 查询部门与子部门树形结构）

> 标注：`staff.GetOrgTree` 未实现，组织架构通过 `department.Get` 递归获取子部门。

## 角色预设

### 企微域（`SetupRoles` 种子）

| 角色 | type | 默认权限 |
|------|------|----------|
| 超级管理员 | superAdmin | 全部菜单 + 全部数据 |
| 管理员 | admin | 管理权限 |
| 部门管理员 | departmentAdmin | 部门级管理 |
| 员工 | staff | 基础业务权限（默认角色） |

### CRM 原生域（`defaultRoles` 种子）

| code | name | 说明 |
|------|------|------|
| `admin` | 租户管理员 | 用户管理/风控/营销等 |
| `manager` | 销售经理 | 用户创建/风控/营销等 |
| `sales` | 销售 | 智能名片（默认角色） |

## 离职继承

详见 [risk/02-客户继承.md](../risk/02-客户继承.md)。

## 注意事项

- **双员工体系**：企微域 Staff（企微同步）与 CRM 原生域 User（本地账号）并存，通过 ChannelLink 映射。
- **角色多对多**：企微 Staff 通过 `role_id` + `role_type` 关联角色；CRM User 通过 `role_id` 关联 CrmRole。
- **离职流程**：**必须执行客户继承**，否则客户丢失。
- **企微同步**：Staff/Department 由企微回调同步，不手动创建。

## 当前限制（**产品补强点**）

- 无岗位体系（职位等级）。
- 无兼职/外包员工模型。
- 无员工操作审计。
- `staff.UpdateStatus / TransferDepartment / GetOrgTree` 未实现。
