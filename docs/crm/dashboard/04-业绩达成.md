# 业绩达成

## 目的
团队/个人业绩目标设定与达成率分析。

## 入口
- 工作台 → 数据看板 → 业绩达成

## 数据模型

### PerformanceTarget（业绩目标）

| 字段 | 说明 |
|------|------|
| `scope` | team / personal |
| `target_id` | 团队 ID / 员工 ID |
| `period` | 2026-Q3 / 2026-08 |
| `metric` | gmv / order_count / new_customers |
| `target_value` | 目标值 |
| `current_value` | 当前值（实时计算） |

## 操作步骤

### 1. 设定目标（主管/管理员）

**接口**：`performance.SetTarget`

```json
{
  "scope": "team",
  "target_id": "sales_team",
  "period": "2026-Q3",
  "metric": "gmv",
  "target_value": 3000000
}
```

### 2. 达成率查询

**接口**：`performance.Achievement(period, scope)`

```json
{
  "period": "2026-Q3",
  "rows": [
    {
      "target_id": "sales_team",
      "metric": "gmv",
      "target_value": 3000000,
      "current_value": 1800000,
      "achievement_rate": 60.0,
      "forecast": 2400000
    }
  ]
}
```

### 3. 业绩排行榜

**接口**：`performance.Ranking(metric, period, scope)`

```json
{
  "rows": [
    {"rank": 1, "staff_id": "2001", "name": "张三", "value": 500000},
    {"rank": 2, "staff_id": "2002", "name": "李四", "value": 400000},
    ...
  ]
}
```

### 4. 趋势分析

**接口**：`performance.Trend(metric, scope, dateRange)`

展示达成进度的时间趋势 + 预测完成情况。

## 达成率分级

| 达成率 | 评级 |
|--------|------|
| ≥ 100% | 优秀 |
| 80%-100% | 良好 |
| 60%-80% | 合格 |
| < 60% | 落后 |

## 预测算法（**当前未实现**）

线性回归：

```go
remaining_days = period_end - today
avg_daily = current_value / elapsed_days
forecast = current_value + avg_daily * remaining_days
```

## 当前限制（**产品补强点**）

- 无目标拆解（季度→月度→周）。
- 无达成预警。
- 无个人/团队目标对比。
