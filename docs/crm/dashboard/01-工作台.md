# 工作台

## 目的
个人/团队工作台首页，一屏看核心数据 + 待办。

## 入口
- 工作台 → 工作台首页

## 数据来源

聚合多个接口：

```json
{
  "todo_count": 8,
  "new_customers_today": 5,
  "followups_due_today": 3,
  "orders_today": 1,
  "gmv_this_month": 50000,
  "rank_in_team": 3
}
```

## 模块构成

### 1. 待办区

来源：[office/05-待办聚合.md](../office/05-待办聚合.md)

展示：跟进/审批/工单/报告 等待办。

### 2. 核心数据卡片

| 卡片 | 含义 |
|------|------|
| 今日新增客户 | 今日 CrmCustomer 新增 |
| 待跟进 | CrmFollowup 状态=pending |
| 今日订单 | CrmOrder 今日创建 |
| 本月 GMV | CrmOrder 本月回款 |

### 3. 待办提醒

- 客户到期未跟进
- 工单超时未处理
- 即将到期合同

### 4. 团队排行

**接口**：`crm_dashboard.Ranking(metric, dateRange)`

返回团队成员的某指标排行（如 GMV 排行）。

### 5. 数据走势图

最近 7 天 / 30 天的新增客户、订单、GMV 折线图。

## 接口

### 1. 工作台首页数据

**接口**：`crm_dashboard.Briefing(staffID)`

聚合：

```go
1. todo_count = todo.ListMyTodos(staffID, pending)
2. new_customers_today = count(CrmCustomer WHERE owner=staffID AND created_at >= today)
3. followups_due = count(CrmFollowup WHERE owner=staffID AND due_at <= today AND status=pending)
4. orders_today = count(CrmOrder WHERE owner=staffID AND created_at >= today)
5. gmv_month = sum(CrmReceivables WHERE received_at >= month_start)
6. rank = staff's ranking in team by gmv_month
```

### 2. 数据趋势

**接口**：`crm_dashboard.Trend(metric, dateRange)`

```json
{
  "by_day": [
    {"date": "2026-08-12", "value": 5},
    {"date": "2026-08-13", "value": 8},
    ...
  ]
}
```

### 3. 团队排行

**接口**：`crm_dashboard.Ranking`

### 4. 团队概览（主管视角）

**接口**：`dashboard.TeamOverview(managerID)`（**未在 dispatch 注册**）

## 注意事项

- **缓存**：工作台首页数据建议**缓存 5 分钟**，避免频繁查询。
- **权限**：按 staff 维度的数据需考虑 data_scope。
- **实时性**：T+1 数据为主，**实时数据依赖流式计算**（**���前未实现**）。
