# 客户继承

## 目的
员工离职/调岗时，客户、群、工单等资源自动分配给接手人。

## 入口
- 企业管理 → 员工管理

## 数��模型

### CustomerTransferLog（继承日志）

| 字段 | 说明 |
|------|------|
| `from_staff_id` | 原员工 |
| `to_staff_id` | 接手员工 |
| `biz_type` | 业务类型（customer / group / workorder / order） |
| `biz_id` | 业务对象 ID |
| `reason` | 原因（leave / transfer） |
| `transferred_at` | 继承时间 |

## 操作步骤

### 1. 员工离职触发

**触发**：staff.UpdateStatus(status=resigned)

```go
1. 查所有 from_staff 拥有的：
   - CrmCustomer WHERE owner_id = from_staff
   - CrmWecomGroup WHERE owner_id = from_staff
   - CrmWorkorder WHERE assignee_id = from_staff
   - CrmOrder WHERE owner_id = from_staff (未完成的)
   - CrmLead WHERE owner_id = from_staff
2. 选 to_staff（按规则：原部门经理/指定接手人）
3. 批量重新分配
4. 每条分配记录 CustomerTransferLog
5. 调用企微 API transfer_external_user / transfer_group
```

### 2. 手动客户转移

**接口**：`crm_customer.Transfer(bizType, bizID, toStaffID, reason)`

### 3. 批量转移

**接口**：`customer_transfer.BatchTransfer`（**未在 dispatch 注册**）

```json
{
  "biz_type": "customer",
  "biz_ids": ["100", "101", "102"],
  "to_staff_id": "2001",
  "reason": "销售张三调岗"
}
```

### 4. 继承规则配置

```json
{
  "rule": "leave_transfer",
  "to_strategy": "department_manager",  // 部门经理
  // or "round_robin",  // 轮询
  // or "specified",  // 指定
  // or "keep_pool",  // 进入公海
}
```

## 继承类型

| biz_type | 转移内容 |
|----------|----------|
| customer | CrmCustomer.owner_id |
| group | CrmWecomGroup.owner_id |
| workorder | CrmWorkorder.assignee_id |
| order | CrmOrder.owner_id |
| lead | CrmLead.owner_id |
| opportunity | CrmOpportunity.owner_id |

## 企微集成

**企微 API**：

```
transfer_external_user:
  external_userid 列表
  handover_userid  = 原员工
  takeover_userid  = 接手员工
  transfer_success_msg = "客户已分配给新同事"

transfer_group:
  chat_id 列表
  handover_userid
  takeover_userid
```

**注意**：企微 API 有频控，**每客户单次最多 100 个**。

## 当前已知问题

- **跨部门转移**：从销售部到客服部，**需业务确认**（如订单是否转移）。
- **接收人接受**：接手员工是否同意接受？**当前默认强制接收**。

## 注意事项

- **不可撤销**：继承日志不可撤销，但**支持手动再转移**。
- **数据完整**：被转移的数据**包括全部历史**（跟进/订单/工单），**不丢失**。

## 当前限制（**产品补强点**）

- 无继承前预览（先看再确认）。
- 无"按客户价值分配"智能路由。
