# 回收站

## 目的
数据软删除 + 恢复 + 定期清理。

## 入口
- 工作台 → 风险合规 → 回收站

## 实现方式

**软删除**：业务表统一有 `deleted_at` 字段（GORM soft delete），删除时只标记，**数据不真删**。

## 操作步骤

### 1. 软删除（业务正常删除）

**接口**：各业务模块的 `Delete`

```go
db.Delete(&entity)  // GORM 自动写 deleted_at = now()
```

### 2. 回收站列表

**接口**：`recycle.List(entity, dateRange)`

聚合所有表的软删除数据，按 entity 分类：

```json
{
  "customer": [
    {"id": "100", "name": "张三", "deleted_at": "2026-08-18 10:00"},
    ...
  ],
  "order": [...],
  "workorder": [...]
}
```

### 3. 恢复数据

**接口**：`recycle.Restore(entity, bizID)`

```go
db.Unscoped().Model(&entity).Where("id = ?", bizID).Update("deleted_at", nil)
```

### 4. 永久删除

**接口**：`recycle.Purge(entity, bizID)`

```go
db.Unscoped().Delete(&entity)
```

**注意**：永久删除**不可恢复**！

### 5. 自动清理

**定时任务**：

```go
每天凌晨清理：
  deleted_at < now - 90 days → 物理删除
```

## 支持软删除的实体

| 实体 | entity |
|------|--------|
| 客户 | customer |
| 订单 | order |
| 商机 | opportunity |
| 工单 | workorder |
| 跟进 | followup |
| 标签 | tag |
| 群 | group |
| 员工 | staff |
| 商品 | product |

## 注意事项

- **唯一性约束**：恢复时需注意唯一键冲突（如手机号）。
- **关联数据**：删除主实体时**需考虑外键**（**当前未启用外键约束**）。
- **审计**：所有删除/恢复操作建议记录操作日志（**当前仅 GORM 自动记录 deleted_at**）。

## 当前限制（**产品补强点**）

- 无回收站分类管理（按 entity）。
- 无批量恢复。
- 无恢复前数据预览。
