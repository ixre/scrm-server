# 敏感词

## 目的
敏感词库管理 + 消息/客户名称等内容的合规审查。

## 入口
- 工作台 → 系统设置 → 敏感词库
- 工作台 → 风险合规 → 审查记录

## 数据模型

### SensitiveWord（敏感词）

| 字段 | 说明 |
|------|------|
| `word` | 词 |
| `category` | 分类（涉政/涉黄/广告/竞品） |
| `level` | high / medium / low |
| `action` | block / replace / warn |
| `replace_word` | 替换词（action=replace 时） |
| `status` | active / disabled |

### SensitiveWordHit（命中记录）

| 字段 | 说明 |
|------|------|
| `word_id` | 敏感词 |
| `biz_type` | 业务类型（message / customer_name / comment） |
| `biz_id` | 业务对象 ID |
| `content` | 原内容 |
| `hit_at` | 命中时间 |

## 操作步骤

### 1. 添加敏感词

**接口**：`sensitive_word.Create`

```json
{
  "word": "加微信",
  "category": "广告",
  "level": "medium",
  "action": "warn"
}
```

### 2. 批量导入

**接口**：`sensitive_word.Import(words []string, category, level)`

从 .txt 文件导入。

### 3. 消息发送前审查

**在 dispatch.Send 之前调用**：

```go
// services/sensitive_word.go:Check
func Check(content string) (passed bool, hits []Hit) {
    for _, word := range GetActiveWords() {
        if strings.Contains(content, word.Word) {
            hits = append(hits, Hit{WordID: word.ID, ...})
            switch word.Action {
            case "block": return false, hits
            case "replace": content = strings.ReplaceAll(content, word.Word, word.ReplaceWord)
            case "warn": /* pass with warning */
            }
        }
    }
    return true, hits
}
```

### 4. 客户名称审查

**在 CrmCustomer.Create 时调用**：

```go
if !sensitive.Check(customer.Name).Passed {
    return error("客户名称包含敏感词")
}
```

### 5. 命中记录查询

**接口**：`sensitive_word.ListHits(dateRange, staffID)`

## 审查策略

| action | 行为 |
|--------|------|
| block | 阻止发送/创建，返回错误 |
| replace | 自动替换敏感词 |
| warn | 允许但记录 + 通知主管 |

## 当前已知问题

- **算法效率**：当前用 `strings.Contains` 遍历所有词，**大数据量下慢**（**待优化** AC 自动机 / Trie 树）。
- **变形词**：拼音 / 火星文 / emoji 变体**当前无法识别**。
- **上下文**：不分上下文（如"苹果"在水果 vs 手机场景下不同）。

## 注意事项

- **不可删除**：命中记录的 word 不可删除，仅可禁用（保留历史）。
- **合规**：涉政/涉黄类敏感词库**不可关闭**。

## 当前限制（**产品补强点**）

- 无 AI 内容审核（图片/语音）。
- 无上下文语义识别。
- 无敏感词库行业模板。
