# 优惠券

## 目的
发放满减/折扣/兑换券，刺激客户复购或拉新。

## 入口
- 工作台 → 营销中心 → 优惠券
- 客户领取（活动/链接/兑换码）
- 订单核销

## 数据模型

### CrmCoupon
`models/crm.go:395-410`：

| 字段 | 说明 |
|------|------|
| `coupon_type` | discount / cash / gift |
| `face_value` | 面值（折扣=0.8，满减=100） |
| `threshold` | 使用门槛（满 X 元可用） |
| `total_count` | 发放总量（0=不限） |
| `issued_count` | 已发放数 |
| `used_count` | 已核销数 |
| `start_at` / `end_at` | 有效期 |

### CrmCouponRecord
`models/crm.go:412-`：

| 字段 | 说明 |
|------|------|
| `coupon_id` | 优惠券模板 |
| `customer_id` | 客户 |
| `code` | 券码（唯一） |
| `status` | issued / used / expired |
| `used_at` | 使用时间 |
| `order_id` | 关联订单 |

## 操作步骤

### 1. 创建优惠券模板

**接口**：`crm_coupon.Create`

```json
{
  "name": "618 满 1000 减 100",
  "coupon_type": "cash",
  "face_value": 100,
  "threshold": 1000,
  "total_count": 10000,
  "start_at": "2026-06-01",
  "end_at": "2026-06-18"
}
```

### 2. 发放优惠券

**接口**：`crm_coupon.Issue`

```json
{
  "coupon_id": "1001",
  "customer_id": "100"
}
```

**自动生成**：`code` 格式 `CP` + 12 位 hex。

### 3. 核销（订单创建时）

在创建订单时传入 `coupon_code`：

```json
{
  "customer_id": "100",
  "amount": 1200,
  "coupon_code": "CP1234567890ab"
}
```

系统自动调 `CrmCoupon.Verify` 核销，订单 `coupon_amount = 100, amount = 1100`。

### 4. 列出发放/核销记录

**接口**：`crm_coupon.ListRecords`

### 5. 查询优惠券详情

**接口**：`crm_coupon.Get`

### 6. 编辑/删除

**接口**：`crm_coupon.Update / Delete`

## 优惠券类型

| coupon_type | 面值字段 | 示例 |
|-------------|---------|------|
| discount | 0.8 表示 8 折 | face_value=0.8, threshold=1000 → 满 1000 打 8 折 |
| cash | 减免金额 | face_value=100, threshold=1000 → 满 1000 减 100 |
| gift | 兑换物 | face_value=0, threshold=0 → 兑换实物 |

## 状态机

```
issued（已发放）──► used（已核销）
       │
       └──► expired（已过期）
```

## 当前已知问题

- **并发扣减**：`UpdateColumn("issued_count", issued_count + 1)` 无乐观锁，**真实并发下可能超发**（**待修复**）。
- **无兑换码体系**：`Issue` 仅直接发，**异业合作场景需补强**。
- **无过期提醒**：券快到期时**无主动提醒**（待补强）。
- **无渠道限制**：`Verify` 不限制核销渠道（线下/线上/特定门店）。

## 注意事项

- **库存检查**：`Issue` 中校验 `issued_count < total_count`。
- **券码唯一**：每个 `CrmCouponRecord` 一码，不可重用。
- **订单关联**：核销时记录 `order_id`，便于后续统计。
- **跨租户禁止**。
