# 裂变

## 目的
邀请好友解锁奖励，低成本获客。

## 入口
- 工作台 → 营销中心 → 裂变
- 客户邀请好友（H5 链接/海报）

## 数据模型

`CrmFission`（`models/crm.go:720-`）：

| 字段 | 说明 |
|------|------|
| `name` | 裂变活动名 |
| `reward_type` | 奖品类型（coupon/cash/gift） |
| `reward_value` | 奖品值 |
| `required_invites` | 需邀请人数 |
| `reward_per_invitee` | 每邀请 1 人额外奖励 |
| `max_rewards_per_user` | 单客户最多领几次 |
| `status` | active / ended |

`CrmFissionRecord`（邀请记录）：

| 字段 | 说明 |
|------|------|
| `fission_id` | 活动 |
| `inviter_id` | 邀请人 |
| `invitee_id` | 被邀请人 |
| `status` | pending（待被邀请人确认）/ confirmed / rewarded |

## 操作步骤

### 1. 创建裂变活动

**接口**：`crm_fission.Create`

```json
{
  "name": "邀好友得 100 元券",
  "reward_type": "coupon",
  "reward_value": 100,
  "required_invites": 3,
  "max_rewards_per_user": 1
}
```

**奖励模型**：
- 邀请满 `required_invites` → 一次性奖励 `reward_value`
- 每邀请 1 人额外奖励 `reward_per_invitee`（阶梯模式）

### 2. 邀请人获取推广链接

**接口**：`crm_fission.GetShareLink(tenantID, fissionID, customerID)`

返回带 `inviter_id` 参数的 H5 链接 + 海报二维码。

### 3. 被邀请人通过链接进入活动

**接口**：`crm_fission.Landing(tenantID, fissionID, inviterID, inviteeID)`

```go
1. 创建 CrmFissionRecord (status=pending)
2. 校验 invitee 是否新用户（创建时间 N 天内）
3. 邀请人数累计（inviter 维度的 count）
4. 校验邀请人是否达到 required_invites → 触发奖励
```

### 4. 自动发奖

```go
if 当前累计 = required_invites:
    CrmCoupon.Issue(customer_id=inviter, coupon_id=100元券)
    CrmFissionRecord.status = rewarded
```

### 5. 列出邀请记录

**接口**：`crm_fission.ListRecords`

## 邀请流程

```
邀请人生成链接 → 分享给好友 → 好友点击进入 → 创建邀请记录 → 校验新用户 → 邀请人数+1 → 达标发奖
```

## 注意事项

- **新用户校验**：通常仅奖励邀请新注册用户（防刷）。
- **设备/IP 限制**：同一设备/IP 多次点击只算 1 次（**当前未实现**）。
- **奖励发放时机**：立即 / 被邀请人下单后（更严格）。
- **刷量检测**：同一客户短时间内多次邀请 → 风险提示。

## 当前限制（**产品补强点**）

- 无多级裂变（仅 1 级）。
- 无阶梯奖励（邀请越多奖越多）。
- 无团队战（PK 邀请人数榜）。
