# 砍价

## 目的
好友帮砍，社交裂变拉新。

## 入口
- 工作台 → 营销中心 → 砍价
- 客户发起砍价 / 好友帮砍（H5）

## 数据模型

`CrmBargain`（`models/crm.go:580-`）：

| 字段 | 说明 |
|------|------|
| `name` | 活动名 |
| `product_name` | 商品 |
| `original_price` | 原价 |
| `min_price` | 最低价（砍到 N 元） |
| `duration_hours` | 活动期 |
| `bargain_rules` | 砍价规则 JSON：`{first_time_min, first_time_max, share_increment_min/max, share_increment_max/max}` |

`CrmBargainRecord`（砍价记录）：

| 字段 | 说明 |
|------|------|
| `bargain_id` | 活动 |
| `initiator_id` | 发起人 |
| `current_price` | 当前价 |
| `min_price` | 砍到的最低 |
| `status` | ongoing / success / expired |

`CrmBargainHelp`（帮砍记录）：

| 字段 | 说明 |
|------|------|
| `bargain_record_id` | 砍价单 |
| `helper_id` | 帮砍人 |
| `cut_amount` | 砍掉金额 |

## 操作步骤

### 1. 创建砍价活动

**接口**：`crm_bargain.Create`

```json
{
  "name": "新用户专享",
  "product_name": "扫地机器人",
  "original_price": 2999,
  "min_price": 999,
  "duration_hours": 48,
  "bargain_rules": {
    "first_time_min": 50,
    "first_time_max": 200,
    "share_increment_min": 5,
    "share_increment_max": 30
  }
}
```

### 2. 客户发起砍价

**接口**：`crm_bargain.Initiate(tenantID, bargainID, customerID)`

```go
1. 校验活动 + 时间
2. 检查客户是否已有进行中的砍价
3. 创建 CrmBargainRecord:
   current_price = original_price
   min_price = bargain.min_price
   status = ongoing
   expire_at = now + duration_hours
4. 发起人首次自己砍一刀（从 first_time_min/max 区间随机）
5. 返还分享链接
```

### 3. 好友帮砍（核心）

**接口**：`crm_bargain.Help(tenantID, bargainRecordID, helperID)`

```go
1. 校验砍价单 status=ongoing + 未过期
2. 检查帮砍人是否已帮过该砍价单（unique 防刷）
3. 随机 cut_amount（从 share_increment_min/max）
4. CrmBargainRecord.current_price -= cut_amount
5. 如果 current_price <= min_price → 锁定 min_price, status=success
6. 创建 CrmBargainHelp 记录
7. 通知发起人
```

### 4. 砍价成功下单

**接口**：`crm_order.Create` 传 `bargain_record_id`

订单金额自动用 `bargain_record.current_price`。

### 5. 砍价过期处理（定时任务）

**接口**：`crm_bargain.ExpireRecords`

```go
扫描 ongoing 且 expire_at < now → status=expired
```

## 状态机

```
ongoing（砍价中）──► success（已砍到底）
     │
     └──► expired（过期）
```

## 注意事项

- **帮砍防刷**：每个 `helper_id` 对每个 `bargain_record_id` 只能帮一次。
- **金额随机**：每次砍价金额在区间内随机，但首次发起有较大区间。
- **最低保护**：砍到 `min_price` 即封顶，不再减少。
- **库存**：砍价活动通常不限库存，但**供应链需考虑**。

## 当前限制（**产品补强点**）

- 无"必须邀请新用户"限制（老带新场景需要）。
- 无排行榜（最牛砍价王）。
- 无分享次数限制防刷。
