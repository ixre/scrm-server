# 秒杀

## 目的
限时+限量抢购，制造紧迫感，刺激快速成交。

## 入口
- 工作台 → 营销中心 → 秒杀
- 客户抢购（H5 / 群消息）

## 数据模型

`CrmSeckill`（`models/crm.go:519-`）：

| 字段 | 说明 |
|------|------|
| `name` | 秒杀活动名称 |
| `product_name` | 商品名 |
| `original_price` | 原价 |
| `seckill_price` | 秒杀价 |
| `total_stock` | 总库存 |
| `left_stock` | 剩余库存 |
| `start_at` / `end_at` | 限时 |

`CrmSeckillRecord`（秒杀记录）：

| 字段 | 说明 |
|------|------|
| `seckill_id` | 活动 |
| `customer_id` | 客户 |
| `status` | success / refunded |

## 操作步骤

### 1. 创建秒杀活动

**接口**：`crm_seckill.Create`

```json
{
  "name": "iPhone 16 秒杀",
  "product_name": "iPhone 16",
  "original_price": 5999,
  "seckill_price": 4999,
  "total_stock": 100,
  "start_at": "2026-08-18T10:00:00Z",
  "end_at": "2026-08-18T12:00:00Z"
}
```

### 2. 客户抢购（核心）

**接口**：`crm_seckill.Grab(tenantID, seckillID, customerID)`

**逻辑**（`services/crm_seckill.go:88`）：

```go
1. 校验活动存在 + 状态 active + 时间范围内
2. 查剩余库存 left_stock
3. 如果 left_stock <= 0 → 返回"已抢光"
4. 乐观锁扣减库存：
   UPDATE crm_seckill SET left_stock = left_stock - 1
   WHERE id = ? AND left_stock > 0
5. 影响行数 = 0 → 抢光，并发安全
6. 创建 CrmSeckillRecord (status=success)
```

**并发安全**：用 `WHERE left_stock > 0` 条件 update，**乐观锁**。

### 3. 列出秒杀记录

**接口**：`crm_seckill.ListRecords(tenantID, seckillID, status, pager)`

### 4. 查询活动

**接口**：`crm_seckill.Query / Get`

## 秒杀流程

```
活动创建 → 库存初始化 → 客户抢购 → 乐观锁扣减 → 创建记录 → （待补强）发券 / 下单
```

## 注意事项

- **乐观锁**：依赖 `left_stock > 0` 条件 update，保证不超卖。
- **一人一单**：建议加 `unique(seckill_id, customer_id)` 防止同一客户多次抢。
- **支付超时**：抢购成功后给 N 分钟支付，超时自动退回库存（**待补强**）。
- **退款联动**：refunded → left_stock += 1（**当前未实现**）。
- **数据一致性**：定时任务校验 `left_stock = total_stock - sum(success)`。

## 当前限制

- 无开抢提醒（订阅通知��**待补强**）
- 无预热（提前 N 分钟预热）
- 无库存补货（卖光后无法补）
