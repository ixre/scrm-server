# 抽奖

## 目的
通过概率游戏提升用户互动，奖品引流。

## 入口
- 工作台 → 营销中心 → 抽奖
- 客户抽奖（活动链接/小程序）

## 数据模型

`CrmLottery`（`models/crm.go:534-`）：

| 字段 | 说明 |
|------|------|
| `name` | 活动名 |
| `prizes` | 奖品列表（JSON）：`[{name, type, value, weight, total, left}]` |
| `start_at` / `end_at` | 活动期 |
| `daily_limit` | 每日抽奖次数限制 |
| `status` | active / ended |

`CrmLotteryRecord`（抽奖记录）：

| 字段 | 说明 |
|------|------|
| `lottery_id` | 活动 |
| `customer_id` | 客户 |
| `prize_name` | 中奖奖品 |
| `prize_type` | coupon / cash / gift / thanks |
| `status` | issued / claimed |

## 操作步骤

### 1. 创建抽奖活动

**接口**：`crm_lottery.Create`

```json
{
  "name": "618 幸运大转盘",
  "prizes": [
    {"name": "优惠券 100 元", "type": "coupon", "value": 100, "weight": 10, "total": 100, "left": 100},
    {"name": "iPhone", "type": "gift", "value": 5999, "weight": 1, "total": 1, "left": 1},
    {"name": "现金红包 1 元", "type": "cash", "value": 1, "weight": 30, "total": 10000, "left": 10000},
    {"name": "谢谢参与", "type": "thanks", "value": 0, "weight": 59, "total": -1, "left": -1}
  ],
  "daily_limit": 3
}
```

**`weight` 总和**：通常设为 100（或归一化）。

### 2. 客户抽奖（核心）

**接口**：`crm_lottery.Draw(tenantID, lotteryID, customerID)`

**逻辑**（`services/crm_lottery.go:Draw`）：

```go
1. 校验活动 + 时间 + daily_limit
2. 查剩余可抽奖品（left > 0 的有库存奖品）
3. 权重随机：weightedRandom(prizes)
   算法：累计权重 → 随机数 → 命中区间
4. 奖品库存扣减：left -= 1
5. 创建 CrmLotteryRecord
6. 自动发奖：
   - coupon 类型 → crm_coupon.Issue
   - cash 类型 → CrmRedPacket.Issue
   - gift 类型 → 发实物领取通知
   - thanks 类型 → 不发奖
```

### 3. 列出抽奖记录

**接口**：`crm_lottery.ListRecords`

### 4. 加权随机算法

```go
func weightedRandom(prizes []LotteryPrize) LotteryPrize {
    total := 0
    for _, p := range prizes {
        total += p.Weight
    }
    r := rand.Intn(total)
    cum := 0
    for _, p := range prizes {
        cum += p.Weight
        if r < cum {
            return p
        }
    }
    return prizes[len(prizes)-1]
}
```

## 当前已知问题

- **无 IP/设备防刷**：同一 IP/设备可无限抽奖（**产品补强点**）。
- **无 anti-bot**：机器人可脚本刷奖（**待补强**）。
- **无大奖播报**：中大奖时无客服介入（用户体验待优化）。

## 注意事项

- **库存耗尽**：所有奖品 `left=0` 时，全部返回 `thanks`。
- **公平性**：权重可调整，但发布后建议锁定。
- **合规性**：现金类奖品注意税务合规。
- **数据一致性**：`left` 字段需与 `total - used` 一致（建议加校验任务）。

## 当前限制（**产品补强点**）

- 仅权重随机，**无大转盘/九宫格/刮刮卡/盲盒等玩法模板**。
- 无多轮抽奖。
- 无积分兑换抽奖。
