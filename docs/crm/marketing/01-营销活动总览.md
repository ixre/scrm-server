# 营销活动总览

## 目的
统一管理营销活动（11 类），提供活动模板、参与记录、效果分析。

## 入口
- 工作台 → 营销中心
- 活动 → 新建活动

## 数据模型

### CrmActivity（活动主表）
`models/crm.go:230-262`：

| 字段 | 说明 |
|------|------|
| `name` | 活动名称 |
| `type` | coupon / lottery / seckill / h5 / group_buy / bargain / full_reduction / red_packet / sign_in / other |
| `status` | draft / active / ended / disabled |
| `start_at` / `end_at` | 活动周期 |
| `channel` | 投放渠道 |
| `rules` | 活动规则 JSON |

### CrmActivityRecord（参与记录）
`models/crm.go:279-`：

| 字段 | 说明 |
|------|------|
| `activity_id` | 关联活动 |
| `customer_id` | 参与客户 |
| `stage` | reach（触达）/ participate（参与）/ convert（转化） |
| `extra` | JSON 扩展数据 |

## 操作步骤

### 1. 创建活动

**接口**：`crm_activity.Create`

```json
{
  "name": "618 大促",
  "type": "coupon",
  "status": "draft",
  "start_at": "2026-06-01",
  "end_at": "2026-06-18",
  "channel": "wecom"
}
```

### 2. 启动活动

**接口**：`crm_activity.Update`

```json
{
  "status": "active"
}
```

### 3. 触达客户

营销活动投放方式：
- 群发消息（依赖 `MassMsg` / `GroupChatMassMsg`）
- SOP 触发（基于客户行为）
- 渠道活码（扫码进入活动）

### 4. 客户参与活动

调用对应子活动的接口（如 `crm_coupon.Issue`）。

### 5. 记录参与（`CrmActivityRecord`）

每类活动的参与都会写一条 `CrmActivityRecord`，包括：
- 触达（reach）：活动展示给客户
- 参与（participate）：客户完成操作（领券/抽奖/拼团）
- 转化（convert）：客户进一步行为（下单/加好友）

### 6. 活动效果分析

**接口**：`crm_report.ActivityFunnel(tenantID)`

```json
{
  "rows": [
    {"activity_id": "1", "reach": 1000, "participate": 300, "convert": 50, "convert_rate": 5.0},
    ...
  ]
}
```

## 活动状态机

```
draft（草稿）──► active（进行中）──► ended（已结束）
   │                  │
   │                  └──► disabled（已停用）
   └──► disabled（已停用）
```

## 注意事项

- **活动周期**：`start_at <= now <= end_at` 才允许客户参与。
- **跨活动**：客户可同时参与多个活动，无互斥。
- **奖品库存**：依赖子表控制（如秒杀库存）。
- **频控**：**当前未实现**（**产品补强点**）。
