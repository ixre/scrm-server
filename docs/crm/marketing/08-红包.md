# 红包

## 目的
现金红包激励（拉新/激活/复购）。

## 入口
- 工作台 → 营销中心 → 红包
- 客户领取/拆红包（活动/链接）

## 数据模型

`CrmRedPacket`（`models/crm.go:640-`）：

| 字段 | 说明 |
|------|------|
| `name` | 红包名 |
| `type` | fixed（定额）/ random（拼手气）/ ladder（阶梯） |
| `total_amount` | 总金额 |
| `total_count` | 总个数 |
| `left_amount` | 剩余金额 |
| `left_count` | 剩余个数 |
| `min_amount` / `max_amount` | 单个红包范围（random） |
| `start_at` / `end_at` | 有效期 |

`CrmRedPacketRecord`（领取记录）：

| 字段 | 说明 |
|------|------|
| `red_packet_id` | 红包 |
| `customer_id` | 领取人 |
| `amount` | 领取金额 |
| `status` | issued / used |
| `claimed_at` | 领取时间 |

## 操作步骤

### 1. 创建红包

**接口**：`crm_red_packet.Create`

```json
{
  "name": "新用户 5 元红包",
  "type": "fixed",
  "total_amount": 50000,
  "total_count": 10000,
  "min_amount": 5,
  "max_amount": 5
}
```

**类型说明**：
- `fixed`：每个红包都是固定金额
- `random`：拼手气，金额在 `min_amount/max_amount` 区间随机
- `ladder`：阶梯红包（金额递减，**待补强**）

### 2. 客户领取（核心）

**接口**：`crm_red_packet.Claim(tenantID, redPacketID, customerID)`

```go
1. 校验活动 + 时间
2. 校验 left_count > 0
3. 计算本次领取金额：
   fixed → max_amount
   random → min/max 之间随机
4. 乐观锁扣减：
   UPDATE crm_red_packet SET
     left_amount = left_amount - amount,
     left_count = left_count - 1
   WHERE id = ? AND left_count > 0 AND left_amount >= amount
5. 影响行数 = 0 → 抢光
6. 创建 CrmRedPacketRecord (amount)
7. 调 crm_coupon.Issue 或直接记账（用于下单核销）
```

### 3. 列出领取记录

**接口**：`crm_red_packet.ListRecords`

### 4. 编辑/删除

**接口**：`crm_red_packet.Update / Delete`

## 状态机

```
created（已创建）──► active（可领取）──► empty（已抢光）
                          │
                          └──► ended（已过期）
```

## 注意事项

- **资金安全**：`left_amount` 与 `total_amount - sum(claimed)` 必须一致，建议定时校验。
- **乐观锁**：领取时用 `WHERE left_count > 0 AND left_amount >= amount` 防止超领。
- **提现 vs 核销**：红包金额可设计为：
  - 直接发到客户余额
  - 仅用于下单核销（更常见，**当前实现**）
- **税务**：单次超过 200 元需上报税务（合规要求）。

## 当前限制（**产品补强点**）

- 无提现到零钱（仅限内部使用）。
- 无阶梯红包。
- 无口令红包。
- 无"必须新用户才能领"限制。
