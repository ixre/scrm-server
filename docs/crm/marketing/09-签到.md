# 签到

## 目的
提升日活/周活，通过连续签到送券激励客户回访。

## 入口
- 工作台 → 营销中心 → 签到
- 客户每日签到（H5 链接）

## 数据模型

`CrmSignIn`（`models/crm.go:680-`）：

| 字段 | 说明 |
|------|------|
| `name` | 签到活动名 |
| `rewards` | 奖励规则 JSON：`{1: 1分, 3: 5元券, 7: 10元券}` |
| `start_at` / `end_at` | 活动期 |
| `status` | active / ended |

`CrmSignInRecord`（签到记录）：

| 字段 | 说明 |
|------|------|
| `sign_in_id` | 活动 |
| `customer_id` | 客户 |
| `sign_date` | 签到日期 |
| `continuous_days` | 连续天数 |
| `reward` | 本次奖励 |

## 操作步骤

### 1. 创建签到活动

**接口**：`crm_sign_in.Create`

```json
{
  "name": "每日签到",
  "rewards": {
    "1": "积分 10",
    "3": "优惠券 5 元",
    "7": "优惠券 20 元",
    "30": "实物大礼包"
  }
}
```

### 2. 客户签到（核心）

**接口**：`crm_sign_in.Sign(tenantID, signInID, customerID)`

```go
1. 校验活动 + 时间
2. 查询上次签到记录（CrmSignInRecord WHERE customer_id ORDER BY sign_date DESC LIMIT 1）
3. 判断连续性：
   last.sign_date == today - 1 day → continuous_days = last.continuous_days + 1
   last.sign_date == today → 重复签到（**返回已签到**）
   否则 → continuous_days = 1
4. 查 rewards 中匹配的天数奖励（取 ≤ continuous_days 的最大 key）
5. 创建 CrmSignInRecord (sign_date=today, continuous_days, reward)
6. 自动发奖：
   - coupon → crm_coupon.Issue
   - 积分 → CrmPoints.Add
   - 实物 → 通知客服
```

### 3. 签到日历查询

**接口**：`crm_sign_in.Calendar(tenantID, signInID, customerID, month)`

返回当月签到日期数组 + 连续天数 + 累计积分。

### 4. 列出签到记录

**接口**：`crm_sign_in.ListRecords`

## 连续性规则

```
3 月 1 日 签到（连续 1 天）
3 月 2 日 签到（连续 2 天）
3 月 4 日 签到（连续 1 天，跳过了 3 日）
3 月 5 日 签到（连续 2 天）
```

## 注意事项

- **一天一次**：同一客户同一天不能重复签到。
- **时区**：按 tenant 时区计算（**当前默认 tenant 字段无时区，需补强**）。
- **断签重置**：跳过一天则重置为 1。
- **补签**：是否允许补签？**当前未实现**。

## 当前限制（**产品补强点**）

- 无补签卡（补签要积分/券购买）。
- 无排行榜（连续天数榜）。
- 无签到提醒（push 推送）。
