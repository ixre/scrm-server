# H5 落地页

## 目的
通过表单落地页收集线索，引流到 CRM。

## 入口
- 客户管理 → 引流获客 → H5落地页
- 编辑器/表单提交

## 数据模型

`CrmLandingPage`（`models/crm.go:494-`）：

| 字段 | 说明 |
|------|------|
| `name` | 落地页名 |
| `title` | 页面标题 |
| `description` | 描述 |
| `cover` | 封面图 |
| `form_fields` | 表单字段 JSON：`[{name, label, type, required}]` |
| `channel` | 投放渠道 |
| `status` | draft / active / archived |
| `view_count` | 浏览量 |
| `submit_count` | 提交量 |

`CrmLandingPageSubmit`（提交记录）：

| 字段 | 说明 |
|------|------|
| `page_id` | 落地页 |
| `form_data` | 表单数据 JSON |
| `customer_id` | 关联客户（自动创建） |
| `source` | UTM 来源 |
| `submitted_at` | 提交时间 |

## 操作步骤

### 1. 创建落地页

**接口**：`crm_landing_page.Create`

```json
{
  "name": "618 留资页",
  "title": "立即预约 618 优惠",
  "description": "留下联系方式，专属顾问 1 对 1 服务",
  "cover": "https://cdn.example.com/cover.jpg",
  "form_fields": [
    {"name": "name", "label": "姓名", "type": "text", "required": true},
    {"name": "mobile", "label": "手机号", "type": "tel", "required": true},
    {"name": "company", "label": "公司", "type": "text", "required": false},
    {"name": "need", "label": "需求", "type": "textarea", "required": false}
  ],
  "channel": "wecom"
}
```

### 2. 客户访问落地页（埋点）

**接口**：`crm_landing_page.TrackView(tenantID, pageID, visitorIP, userAgent)`

> ⚠️ **未在 dispatch 注册**（dispatch 仅注册 Create/Query/Get/Delete）。

```go
1. CrmLandingPage.view_count += 1
2. （**待补强**）UV 独立访客统计
```

### 3. 客户提交表单（核心）

**接口**：`crm_landing_page.Submit(tenantID, pageID, formData, source)`

> ⚠️ **未在 dispatch 注册**（dispatch 仅注册 Create/Query/Get/Delete）。

```go
1. 校验 form_data 必填字段
2. 通过 mobile 去重：
   找到 CrmCustomer → 更新
   找不到 → 创建 CrmCustomer (channel=landing_page, source=source)
3. 创建 CrmLandingPageSubmit 记录
4. CrmLandingPage.submit_count += 1
5. 创建跟进任务（**待补强**自动分配销售）
6. 触发 SOP（如有）
7. 返回成功
```

### 4. 列出提交记录

**接口**：`crm_landing_page.ListSubmits`

> ⚠️ **未在 dispatch 注册**（dispatch 仅注册 Create/Query/Get/Delete）。

### 5. 效果分析

**接口**：`crm_landing_page.Stats(tenantID, pageID)`

> ⚠️ **未在 dispatch 注册**（dispatch 仅注册 Create/Query/Get/Delete）。

```json
{
  "view_count": 1000,
  "submit_count": 100,
  "submit_rate": 10.0,
  "by_day": [
    {"date": "2026-08-18", "view": 100, "submit": 10},
    ...
  ]
}
```

## 表单字段类型

| type | 控件 |
|------|------|
| text | 单行输入 |
| textarea | 多行输入 |
| tel | 手机号 |
| email | 邮箱 |
| number | 数字 |
| select | 下拉选择 |
| checkbox | 多选 |
| radio | 单选 |
| date | 日期选择 |
| file | 文件上传 |

## 注意事项

- **去重**：通过 mobile 字段判断是否已存在客户（**手机号为空时无法去重**）。
- **分配销售**：提交后是否自动分配？**当前未实现，需手动或定时任务分配**。
- **隐私合规**：手机号等敏感字段需符合《个人信息保护法》。
- **渠道追踪**：通过 UTM 参数记录 source。

## 当前限制（**产品补强点**）

- 无可视化拖拽编辑器（**仅有 JSON 字段配置**）。
- 无 A/B 测试。
- 无独立域名（使用系统域名）。
