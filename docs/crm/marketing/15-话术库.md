# 话术库

## 目的
按场景沉淀销售话术，提升沟通效率。

## 入口
- 工作台 → 营销中心 → 话术库
- 跟进沟通页面 → 推荐话术

## 数据模型

`CrmSalesScript`（`models/crm.go`）：

| 字段 | 说明 |
|------|------|
| `name` | 话术名 |
| `category` | 分类（welcome / follow_up / objection / close） |
| `content` | 话术内容 |
| `tags` | 标签（适用场景） |
| `usage_count` | 使用次数 |
| `status` | active / archived |

## 操作步骤

### 1. 创建话术

**接口**：`crm_script.Create`

```json
{
  "name": "客户问价格时的话术",
  "category": "objection",
  "content": "理解您对价格的关注，我们的服务其实包含……",
  "tags": ["价格异议", "B2B"]
}
```

### 2. 分类管理

| category | 适用场景 |
|----------|----------|
| welcome | 新客��欢迎 |
| follow_up | 跟进客户 |
| objection | 异议处理 |
| close | 逼单成交 |
| aftersale | 售后 |
| birthday | 生日祝福 |
| festival | 节日问候 |

### 3. 跟进沟通页推荐

在工作台跟进沟通页面输入关键词，系统按 `tags` 推荐话术：

**接口**：`crm_script.Recommend(tenantID, context)`

```go
1. 解析 context（场景：price / welcome / close）
2. 查 category + tag 匹配的话术
3. 按 usage_count 排序返回 top 5
```

### 4. 使用统计

**接口**：`crm_script.UsageStats(tenantID, scriptID)`

每个员工/全公司的使用次数。

## 话术示例

**新人欢迎话术**：
> 您好，欢迎咨询～我是您的专属顾问 [姓名]。有任何问题可以随时联系我，我们的服务包含……

**价格异议**：
> 理解您对价格的关注。我们对比同行，性价比更优：1. 包含 X 服务 2. 24h 客服响应 3. 7 天无理由退款。

**逼单**：
> 这款产品今天下单享 8 折优惠，仅剩 [N] 个名额。需要我帮您下单吗？

## 注意事项

- **合规**：话术中**禁止夸大、虚假承诺**（避免合规风险）。
- **个性化**：话术是模板，**实际发送需员工个性化**。
- **使用记录**：是否记录员工发了哪条话术？**当前仅记 usage_count，不记具体发送**。

## 当前限制（**产品补强点**）

- 无 AI 推荐话术（按对话上下文）。
- 无话术效果追踪（用了话术的转化率）。
- 无团队共享话术 vs 个人话术区分。
- 无话术版本管理。
