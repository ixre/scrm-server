# 拼团

## 目的
多人成团享受低价，老客带新客。

## 入口
- 工作台 → 营销中心 → 拼团
- 客户开团/参团（H5 链接）

## 数据模型

`CrmGroupBuy`（`models/crm.go:560-`）：

| 字段 | 说明 |
|------|------|
| `name` | 拼团活动名 |
| `product_name` | 商品 |
| `original_price` | 原价 |
| `group_price` | 拼团价 |
| `required_count` | 成团人数（2/3/5） |
| `duration_hours` | 团有效期 |
| `status` | active / ended |

`CrmGroupBuyTeam`（团）：

| 字段 | 说明 |
|------|------|
| `group_buy_id` | 活动 |
| `leader_id` | 团长 |
| `current_count` | 当前人数 |
| `required_count` | 成团人数 |
| `status` | forming / success / failed |
| `expire_at` | 团过期时间 |

`CrmGroupBuyMember`（团员）：

| 字段 | 说明 |
|------|------|
| `team_id` | 团 |
| `customer_id` | 客户 |
| `is_leader` | 是否团长 |

## 操作步骤

### 1. 创建拼团活动

**接口**：`crm_group_buy.Create`

```json
{
  "name": "3 人成团",
  "product_name": "空气净化器",
  "original_price": 2999,
  "group_price": 1999,
  "required_count": 3,
  "duration_hours": 24
}
```

### 2. 客户开团（核心）

**接口**：`crm_group_buy.StartTeam(tenantID, groupBuyID, customerID)`

```go
1. 校验活动 + 时间
2. 检查客户是否已有未结束团（CrmGroupBuyMember JOIN）
3. 创建 CrmGroupBuyTeam (status=forming, current_count=1, expire_at=now+24h)
4. 创建 CrmGroupBuyMember (is_leader=true)
5. 返回 team_id + 分享链接
```

### 3. 客户参团（核心）

**接口**：`crm_group_buy.JoinTeam(tenantID, teamID, customerID)`

```go
1. 校验团存在 + status=forming + 未过期 + current_count < required_count
2. 检查客户是否已在该团
3. 创建 CrmGroupBuyMember
4. current_count += 1
5. 如果 current_count == required_count → status=success → 触发成团通知/订单
```

### 4. 团过期处理（定时任务）

**接口**：`crm_group_buy.ExpireTeams`

```go
定时扫描 forming 且 expire_at < now 的团 → status=failed → 通知未成团成员
```

### 5. 列出团/团员

**接口**：`crm_group_buy.ListTeams / ListMembers`

## 注意事项

- **库存**：团购活动通常不限库存，但**需考虑供应链**（**待补强**）。
- **退团**：成团前可退团（**当前未实现**）。
- **退款**：失败团自动退款（**当前未实现**）。
- **并发**：同时参团时用乐观锁避免 `current_count` 超额。

## 当前限制（**产品补强点**）

- 无"老带新"奖励（团长额外奖）。
- 无拼团机器人（凑人数）。
- 无团长免单玩法。
- 无阶梯团（人数越多越便宜）。
