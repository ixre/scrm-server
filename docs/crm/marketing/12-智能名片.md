# 智能名片

## 目的
销售的社交名片，支持客户加好友、查看动态、分享。

## 入口
- 工作台 → 营销中心 → 智能名片
- 个人名片（H5 链接/小程序码）

## 数据模型

`CrmSmartCard`（`models/crm.go:840-860`）：

| 字段 | 说明 |
|------|------|
| `name` | 名片名（如"销售小张"） |
| `owner_id` | 所属员工 |
| `avatar` | 头像 |
| `title` | 职位 |
| `company` | 公司 |
| `phone` / `email` / `wechat` | 联系方式 |
| `intro` | 个人简介 |
| `tags` | 个人标签 |
| `view_count` | 浏览量 |
| `share_count` | 分享次数 |
| `share_code` | 分享码（短链） |

## 操作步骤

### 1. 创建智能名片

**接口**：`crm_smart_card.Create`

```json
{
  "name": "销售小张",
  "owner_id": "2001",
  "title": "高级销售经理",
  "company": "Acme Corp",
  "phone": "13800138000",
  "wechat": "zhangsan_wx",
  "intro": "专注企业服务 10 年",
  "tags": ["B2B", "SaaS", "顾问"]
}
```

### 2. 客户访问名片（埋点）

**接口**：`crm_smart_card.TrackView(tenantID, cardID)`

```go
CrmSmartCard.view_count += 1
```

### 3. 一键加好友（核心）

**接口**：`crm_smart_card.AddContact(tenantID, cardID, customerID)`

```go
1. 校验名片存在
2. 创建 CrmChannelInteraction（如果客户是从微信扫名片码）
3. 关联到 owner 的客户列表
4. 触发 SOP（如果有）
```

### 4. 分享名片（生成短链/海报）

**接口**：`crm_smart_card.GenerateShare(tenantID, cardID)`

```go
生成 share_code + 海报图（含二维码）
返回短链 URL
```

### 5. 浏览量/分享量统计

**接口**：`crm_smart_card.Stats(tenantID, cardID)`

返回 PV/UV + 分享次数 + 加好友次数。

## 名片场景

| 场景 | 用途 |
|------|------|
| 展会 | 现场扫码加好友 |
| 朋友圈 | 分享个人品牌 |
| 客户介绍 | 销售给客户发名片 |
| 招聘 | HR 招聘名片 |

## 注意事项

- **隐私保护**：员工手机号、微信号是敏感信息，**仅自己/管理员可见**，客户访问时建议走中间号或企微活码。
- **数据隔离**：名片属于员工个人，但**统计属于公司**。
- **动态**：是否支持名片动态（朋友圈式）？**当前未实现**。

## 当前限制（**产品补强点**）

- 无个人动态/朋友圈。
- 无名片点赞/评论。
- 无雷达（实时通知谁看了我的名片）。
