# 报价单（Quote）

## 目的
向客户展示方案和价格，作为订单签订前的最终确认。

## 入口
- 工作台 → 报价管理
- 商机详情 → 创建报价

## 数据模型

`CrmQuote`（`models/crm.go:936-`）：

| 字段 | 说明 |
|------|------|
| `customer_id` / `opportunity_id` | 关联客户/商机 |
| `quote_no` | 报价单号 |
| `title` | 报价标题 |
| `amount` | 报价金额 |
| `valid_until` | 有效期 |
| `status` | draft / sent / accepted / rejected / expired |
| `product_details` | 产品明细 JSON |
| `user_id` | 创建销售 |
| `discount` | 折扣 |

## 操作步骤

### 1. 创建报价单

**接口**：`crm_quote.Create`

```json
{
  "customer_id": "1001",
  "opportunity_id": "2001",
  "title": "SCRM 企业版 100 用户报价",
  "amount": 500000,
  "valid_until": "2026-09-30",
  "product_details": [
    {"name": "SCRM 企业版", "spec": "100 用户/年", "qty": 1, "price": 500000, "amount": 500000}
  ]
}
```

**自动生成**：`quote_no` 格式 `QT202608180001`（年月日+序号）。

### 2. 更新报价

**接口**：`crm_quote.Update`

### 3. 状态变更

**接口**：`crm_quote.ChangeStatus`

```json
{
  "id": "5001",
  "status": "sent"  // draft → sent → accepted/rejected
}
```

### 4. 报价转订单（**当前未实现，建议补强**）

**接口**：`crm_quote.ConvertToOrder`（**待补强**）

**建议流程**：
1. 校验 status = accepted
2. 创建 CrmOrder（amount/title/product_details 从 quote 拷贝）
3. 关联 `from_quote_id`
4. 触发 SOP（合同签订 SOP）

### 5. 报价转移

**接口**：`crm_quote.Transfer(tenantID, id, toUserID)`

### 6. 报价作废

**接口**：`crm_quote_ext.Void`

### 7. 查询报价

**接口**：`crm_quote.Query`

支持：
- 客户 ID
- 商机 ID
- 状态
- 创建时间范围

## 报价生命周期

```
draft ──► sent ──► accepted ──► (转订单) ──► completed
              │
              └────► rejected
              │
              └────► expired (有效期过)
```

## 注意事项

- **草稿可改**：status=draft 可修改任何字段，sent 之后只能修改备注。
- **有效期**：valid_until 过期后状态自动变 expired（需定时任务，建议加）。
- **金额锁定**：accepted 后不可修改 amount。
- **当前缺口**：
  - ❌ 无版本管理（同客户多版本报价）
  - ❌ 无报价审批流
  - ❌ 无报价转订单接口
  - ❌ 无到期提醒任务
