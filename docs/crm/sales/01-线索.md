# 线索（Lead）

## 目的
收集潜在客户信息，经过筛选后转为正式客户。

## 入口
- 工作台 → 线索
- 营销活动参与自动创建线索
- H5 落地页提交自动创建线索

## 数据模型

`CrmLead`（`models/crm.go:104-125`）：

| 字段 | 说明 |
|------|------|
| `customer_id` | 关联客户（可空，转客户后回填） |
| `owner_user_id` | 归属销售 |
| `title` | 线索标题 |
| `company` | 公司 |
| `name` / `mobile` / `email` / `position` | 联系人信息 |
| `source` | 来源渠道 |
| `status` | new / contacted / qualified / lost |
| `pool_status` | 0-非池 / 1-池中 |
| `convert_customer_id` | 转客户后的客户 ID |
| `convert_at` | 转化时间 |
| `convert_remark` | 转化备注 |

## 操作步骤

### 1. 手动创建线索

**接口**：`crm_lead.Create`

```json
{
  "title": "张总咨询产品",
  "name": "张三",
  "mobile": "13800138000",
  "company": "ACME",
  "source": "manual",
  "remark": "朋友介绍"
}
```

### 2. 查询线索

**接口**：`crm_lead.Query`

支持过滤：
- `keyword`：模糊匹配
- `status`
- `owner_user_id`
- `source`

### 3. 更新线索

**接口**：`crm_lead.Update`

### 4. 删除线索

**接口**：`crm_lead.Delete`

### 5. 移动到线索池

**接口**：`crm_lead_ext.MoveToPool(tenantID, ids)`

将线索 `pool_status=1, pool_at=now`。

### 6. 销售从线索池认领

**接口**：`crm_lead_ext.ReceiveFromPool(tenantID, userID, id)`

**逻辑**：把线索 `pool_status=0, owner_user_id=userID, pool_at=null`。

### 7. 列出线索池

**接口**：`crm_lead_ext.ListPool(tenantID, req)`

支持分页和关键字搜索。

### 8. 线索转移

**接口**：`crm_lead_ext.Transfer(tenantID, id, toUserID)`

### 9. 线索转客户（核心操作）

**接口**：`crm_lead_ext.ConvertToCustomer(tenantID, userID, id, remark)`

**流程**（`services/crm_lead_ext.go`）：

1. 读取线索，校验状态
2. 创建 CrmCustomer（按 mobile 去重）
3. 创建 ChannelLink
4. 更新线索：`customer_id, convert_at, convert_remark, status=qualified`
5. 触发 SOP（新客户欢迎 SOP）

```json
{
  "id": "1001",
  "remark": "客户意向明确"
}
```

返回：创建的 CrmCustomer 对象。

## 线索状态机

```
new ──► contacted ──► qualified ──► (转客户)
                                       │
                              lost（标记输单）
```

**状态变更**：
- 手动 Update
- 转客户自动 → qualified
- 标记输单 → lost

## 线索池规则（建议）

| 规则 | 默认 |
|------|------|
| 7 天未跟进 → 入池 | 可配 |
| 30 天未成交 → 入池 | 可配 |
| 手动释放 → 入池 | ✅ |

## 注意事项

- **线索 vs 客户**：线索是"未确认"，客户是"已确认"。转化是单向的。
- **重复 mobile**：线索转客户时按 mobile 去重，已存在的客户则补关联 `customer_id`。
- **线索池优先级**：从池中认领的线索不抢单，按先到先得。
- **转换后业务**：触发 SOP（新客户 SOP），可发欢迎语 / 加好友任务。
