# 售后（Aftersales）

## 目的
跟踪客户购买后的退换货 / 投诉 / 维修等服务请求。

## 入口
- 客服 → 售后管理
- 订单详情 → 申请售后
- 客户 → 公众号菜单/H5 提交售后

## 数据模型

`CrmAftersales`（`models/crm.go:1370-`）：

| 字段 | 说明 |
|------|------|
| `aftersales_no` | 售后单号 |
| `customer_id` | 关联客户 |
| `order_id` | 关联订单 |
| `type` | refund / return / exchange / repair |
| `status` | pending / approved / rejected / processing / completed |
| `reason` | 售后原因 |
| `amount` | 退款/补差金额 |
| `product_details` | 商品明细 |
| `attachments` | 图片凭证 |
| `processor_id` | 处理人 |

`CrmAftersalesType`（售后类型）：退款/退货/换货/维修/其他。

`CrmAftersalesComment`（售后评论）：团队内部沟通。

## 操作步骤

### 1. 创建售后

**接口**：`crm_aftersales.Create`

```json
{
  "customer_id": "1001",
  "order_id": "5001",
  "type": "refund",
  "reason": "产品不匹配需求",
  "amount": 50000,
  "product_details": [
    {"name": "SCRM 企业版", "qty": 1, "amount": 50000}
  ]
}
```

**自动生成**：`aftersales_no` 格式 `AS202608180001`。

### 2. 售后类型管理

**接口**：`crm_aftersales_type.Create / Update / Delete / Query`

### 3. 状态变更

**接口**：`crm_aftersales.ChangeStatus`

```json
{
  "id": "7001",
  "status": "approved"
}
```

### 4. 售后评论

**接口**：`crm_aftersales_comment.Create / List / Delete`

```json
{
  "aftersales_id": "7001",
  "content": "客户上传了发票照片，待财务核实"
}
```

### 5. 售后转工单

**当前**：手动转工单（重新创建 `CrmWorkorder`）。

**建议补强**：自动创建工单并关联 `from_aftersales_id`。

### 6. 退款联动

**当前**：
- 售后 type=refund 审批通过
- 财务手动登记 `CrmReceivables`（负金额）

**建议补强**：自动冲销订单 `paid_amount`，创建 `CrmFinanceRecord`（支出）。

## 售后状态机

```
pending（待审批）
   │
   ├──► approved（已批准）
   │      │
   │      ├──► processing（处理中）
   │      │
   │      └──► completed（已完成）
   │
   └──► rejected（已拒绝）
```

## 售后类型

| type | 用途 |
|------|------|
| refund | 仅退款 |
| return | 退货退款 |
| exchange | 换货 |
| repair | 维修 |
| other | 其他 |

## 注意事项

- **金额限制**：amount ≤ 订单金额。
- **订单关联**：售后必须关联订单（验证订单归属）。
- **附件必填**：建议退换货必须上传图片凭证。
- **审批**：建议金额 > 1000 自动触发审批流。
- **退款通道**：原路返回（微信/支付宝/银行卡）。
- **当前缺口**：
  - ❌ 无自动转工单
  - ❌ 无退款入账自动联动
  - ❌ 无审批流
