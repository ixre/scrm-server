# 回款（Receivables）

## 目的
记录实际收款，与订单、回款计划匹配。

## 入口
- 工作台 → 回款管理
- 订单详情 → 登记回款
- 财务 → 回款录入

## 数据模型

### CrmReceivablesPlan（回款计划）
`models/crm.go:897-`：

| 字段 | 说明 |
|------|------|
| `order_id` | 关联订单 |
| `customer_id` | 关联客户 |
| `due_at` | 应收日期 |
| `amount` | 应收金额 |
| `status` | pending / partial / paid / overdue |

## 操作步���

### 1. 创建回款计划

**接口**：`crm_receivables_plan.Create` 或 `BatchCreate`

```json
{
  "order_id": "5001",
  "customer_id": "1001",
  "due_at": "2026-09-30",
  "amount": 250000,
  "remark": "第二期 50%"
}
```

或批量：

```json
{
  "plans": [
    {"order_id": "5001", "due_at": "2026-08-18", "amount": 150000},
    {"order_id": "5001", "due_at": "2026-09-30", "amount": 350000}
  ]
}
```

### 2. 登记回款

**接口**：`crm_receivables.Create`

```json
{
  "order_id": "5001",
  "plan_id": "3001",
  "customer_id": "1001",
  "amount": 150000,
  "payment_method": "银行转账",
  "remark": "客户已打款"
}
```

**副作用**：
- 订单 `paid_amount += 150000`
- 回款计划 `paid_amount += 150000`，更新 status
- 订单 `pay_status` 自动更新：unpaid → partial → paid

### 3. 回款作废

**接口**：`crm_receivables.Void`

**逻辑**：
- 回款 status = void
- 订单 paid_amount -= amount（冲销）

### 4. 自动标记逾期

**接口**：`crm_receivables_plan.MarkOverdue`

**定时任务**：`tasks/crm_automation.go`（**当前未自动跑，需手动调用**）

```sql
UPDATE crm_receivables_plan
SET status = 'overdue'
WHERE due_at < now() AND status = 'pending'
```

### 5. 到期提醒（**当前未实现，建议补强**）

**建议补强**：

定时任务每天扫描 3 天内到期的计划，发通知给销售 + 客户。

```go
plans := getPlansDueSoon(3 days)
for _, plan := range plans {
    notifySales(plan.OwnerUserID, plan)

```

### 6. 查询

**接口**：
- `crm_receivables.Query`：按订单/客户/状态/时间筛选
- `crm_receivables_plan.Query`：按订单/状态/到期时间

### 7. 应收汇总

**接口**：`crm_receivables.Summary`

返回：
- 总应收
- 总已收
- 总未收
- 逾期金额

## 回款流程

```
订单创建
   │
   ▼
创建回款计划（1-N 期）
   │
   ▼
每期到期前 3 天：提醒销售和客户（待补强）
   │
   ▼
客户付款 → 财务登记回款
   │
   ▼
订单 paid_amount += 实收
   │
   ▼
全部到账 → 订单 pay_status = paid
```

## 状态联动

| 回款计划状态 | 触发条件 |
|--------------|---------|
| pending | 新建 |
| partial | 部分收款 |
| paid | 全额收款 |
| overdue | 超期未收 |

| 订单 pay_status | 触发条件 |
|-----------------|---------|
| unpaid | 无收款 |
| partial | 部分收款 |
| paid | 全额收款 |

## 注意事项

- **订单一致性**：paid_amount ≤ amount。
- **作废谨慎**：作废回款会冲销订单，建议加审批。
- **跨订单回款**：单次回款仅关联一个订单，跨订单回款需创建多条。
- **多币种**：**当前未支持**（产品补强点）。
- **发票联动**：回款登记后可创建发票申请。
