# 订单（Order / 合同）

## 目的
记录客户签订合同 / 下单的事实，作为后续交付和回款的依据。

## 入口
- 工作台 → 订单管理
- 商机详情 → 创建订单
- 客户 360 → 创建订单

## 数据模型

### CrmOrder（订单）
`models/crm.go:183-214`：

| 字段 | 说明 |
|------|------|
| `customer_id` / `opportunity_id` | 关联客户/商机 |
| `order_no` | 订单号（租户内唯一） |
| `title` | 订单标题 |
| `amount` | 订单金额 |
| `paid_amount` | 已收金额 |
| `status` | draft / signed / completed / cancelled |
| `pay_status` | unpaid / partial / paid |
| `signed_at` | 签约时间 |
| `coupon_id` | 关联优惠券 |
| `coupon_amount` | 优惠券抵扣金额 |
| `contract_ratio` | 业绩分成比例（**待补强**） |
| `user_id` | 签约销售 |

## 操作步骤

### 1. 创建订单

**接口**：`crm_order.Create`

```json
{
  "customer_id": "1001",
  "opportunity_id": "2001",
  "title": "SCRM 企业版 100 用户 1 年",
  "amount": 500000,
  "coupon_code": "CP123456",
  "signed_at": "2026-08-18",
  "remark": "年度服务"
}
```

**自动生成**：`order_no` 格式 `SO202608180001`。

**注意**：
- 传入 `coupon_code` 时自动核销（`CrmCoupon.Verify`），抵扣金额写入 `coupon_amount`。
- 创建时若 status=signed，自动创建回款计划（建议）。

### 2. 更新订单

**接口**：`crm_order.Update`

### 3. 删除订单

**接口**：`crm_order.Delete`（仅 draft 可删）

### 4. 状态变更

**接口**：`crm_order_ext.ChangeStatus`

```json
{
  "id": "5001",
  "status": "completed"  // 订单完成（已交付）
}
```

**状态机**（**当前简化，建议补强**）：

```
draft ──► signed ──► completed
            │
            └────► cancelled
```

**建议补强**：增加 `pending_payment / partial_paid / fulfilled` 等中间态。

### 5. 订单进度节点

**接口**：`crm_order_progress.Create`

```json
{
  "order_id": "5001",
  "title": "客户已付款",
  "content": "首付款 30% 已到账"
}
```

**用途**：订单执行过程留痕，可作为交付时间线展示。

### 6. 上传合同附件

**接口**：`crm_order_attachment.Upload`

### 7. 创建回款计划（建议与订单同步）

**接口**：`crm_receivables_plan.BatchCreate`

```json
{
  "plans": [
    {"order_id": "5001", "due_at": "2026-08-18", "amount": 150000, "remark": "首付 30%"},
    {"order_id": "5001", "due_at": "2026-11-18", "amount": 350000, "remark": "尾款 70%"}
  ]
}
```

### 8. 订单取消

**接口**：`crm_order_ext.Cancel`

**逻辑**：
- `status = cancelled`
- 已核销优惠券退还（**待补强**）

### 9. 退换货流程（**当前未实现，建议补强**）

**建议补强**：
- `CrmReturnOrder` 模型（退货原因、退款金额、商品列表）
- 退货审批流
- 退款入账到 CrmReceivables（冲销原订单已收）

## 订单状态机

```
draft（草稿）
   │
   ▼
signed（已签约）
   │
   ├──► completed（已完成）
   │
   └──► cancelled（已取消）
```

**联���事件**：
- draft → signed：触发"合同签订 SOP" / 创建回款计划
- signed → completed：触发"订单完成 SOP"（评价邀请 / 续费提醒）
- signed → cancelled：触发"订单取消 SOP" / 优惠券退还

## 订单与回款联动

```
创建订单
  ↓
创建回款计划（BatchCreate）
  ↓
到期前 3 天：自动提醒（待补强）
  ↓
回款登记（CrmReceivables.Create）
  ↓
paid_amount += amount
  ↓
全部回款 → pay_status = paid
```

## 注意事项

- **订单号唯一**：同租户内 order_no 唯一。
- **金额一致性**：paid_amount ≤ amount。
- **状态限制**：signed/completed 不可删除。
- **优惠券**：创建订单时传入 coupon_code 自动核销，仅一次。
- **业绩归属**：user_id 决定业绩归属（**多人分成待补强**）。
- **当前缺口**：
  - ❌ 无状态机强制校验
  - ❌ 无主动通知客户机制
  - ❌ 无退换货流程
  - ❌ 无多人分成
