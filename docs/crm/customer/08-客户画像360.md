# 客户画像 360

## 目的
销售查看单个客户的全部信息聚合（跟进/订单/工单/互动/标签/评分/转移），形成客户全景视图。

## 入口
- 工作台 → 客户管理 → 客户详情
- 任意客户列表行 → 点击

## 数据模型

### CrmCustomer 主档
（参见 [01-客户主档.md](01-客户主档.md)）

### 关联表（聚合来源）
- `CrmFollowup` 跟进记录
- `ChatMsg` 企微聊天记录
- `CrmChannelInteraction` 渠道互动
- `CrmActivityRecord` 营销活动参与
- `CrmTransferLog` 转移日志
- `CrmOrder` 订单（**当前未聚合，建议补强**）
- `CrmReceivables` 回款（**当前未聚合，建议补强**）
- `CrmWorkorder` 工单（**当前未聚合，建议补强**）
- `CrmQuote` 报价（**当前未聚合，建议补强**）

## 操作步骤

### 1. 查看客户 360 详情

**接口**：`crm_customer.GetDetail(tenantID, id)`

**返回**（`services/crm.go:898-937`）：

```json
{
  "customer": { ... 主档 ... },
  "followups": [ ... 跟进记录（按时间倒序） ... ],
  "wecom_messages": [ ... 企微聊天记录（最近 20 条） ... ],
  "channel_interactions": [ ... 非企微渠道互动 ... ],
  "activity_records": [ ... 营销活动参与史 ... ],
  "transfer_logs": [ ... 转移历史 ... ]
}
```

### 2. 客户时间线（前端展示）

前端聚合所有上述数据，按时间倒序排列：

```
2026-08-18 10:30  销售 A 创建客户
2026-08-18 11:00  小红书留资（来源：Xiaohongshu Lead）
2026-08-19 09:00  销售 A 跟进（type=call，result=positive）
2026-08-20 14:00  参加"618 优惠券活动"
2026-08-21 10:00  创建商机"采购 100 套"
2026-08-22 15:00  发送报价单
2026-08-25 09:00  客户签合同
2026-08-26 18:00  转账回款（应收 ¥50000）
2026-09-01 11:00  客户报修（创建工单）
2026-09-02 16:00  工单解决（满意度 5 星）
```

### 3. 跟进视图

**接口**：`crm_followup.ListByCustomer(tenantID, customerID)`

返回该客户的所有跟进，按时间倒序。

### 4. 互动视图

**接口**：`crm_channel_interaction.Query`

返回该客户在各渠道的互动（评论、私信、留资）。

**注意**：企微互动在 `ChatMsg`，不在 `CrmChannelInteraction`。

### 5. 活动参与史

**接口**：`crm_activity.ListByCustomer(tenantID, customerID)`

返回该客户参与的所有营销活动记录。

### 6. 转移历史

**接口**：`crm_transfer.ListTransferLog(tenantID, customerID, pager)`

返回该客户的转移记录（包含时间、原因）。

## 客户标签展示

前端在客户头部展示：
- 渠道标签（彩色徽章）
- 客户等级（潜在/普通/重要/重点/VIP）
- 是否重点客户
- 是否锁客
- 是否黑名单
- 客户评分（数字）

## 注意事项

- **大数据量**：老客户可能有几百条跟进 / 几千条互动，列表要分页加载。
- **跨租户禁止**：所有查询必须带 tenant_id。
- **权限控制**：销售仅看自己的客户（含共享）。
- **渠道隔离**：企微互动走 chat_msg，其他渠道走 ChannelInteraction。
- **AI 增强**：未来可加 LLM 自动生成"客户摘要"。
