# 客户评分

## 目的
按规则自动给客户打分，让销售聚焦高价值客户。

## 入口
- 工作台 → 客户排行榜
- 设置 → 评分规则（待实现可视化）

## 数据模型

### CrmCustomer 评分字段
- `score` int：0-100 分（默认 0）
- `score_updated_at`：评分更新时间

### CrmScoreService（评分服务）
`services/crm_score.go`：

| 方法 | 用途 |
|------|------|
| `RecalculateAll(tenantID)` | 全量重算 |
| `CalculateScore(c)` | 单客户算分 |
| `TopByScore(tenantID, limit)` | 取 Top 客户 |

## 评分公式（`CalculateScore`）

```go
func (s CrmScoreService) CalculateScore(c models.CrmCustomer) int {
    score := 0
    // 1. 基础分 50
    score += 50
    
    // 2. 互动次数（最多 +20）
    interactions := countInteractions(c)
    score += min(interactions * 2, 20)
    
    // 3. 跟进次数（最多 +10）
    followups := countFollowups(c)
    score += min(followups, 10)
    
    // 4. 订单金额（最多 +20）
    if totalOrderAmount >= 10000 { score += 20 }
    else if totalOrderAmount >= 1000 { score += 10 }
    else if totalOrderAmount > 0 { score += 5 }
    
    return min(score, 100)
}
```

**评分维度**（当前为简化版）：
- 基础分 50
- 渠道互动次数（最多 +20）
- 跟进次数（最多 +10）
- 累计订单金额（+5/+10/+20）

## 操作步骤

### 1. 单客户评分重算

**接口**：`crm_score.RecalculateAll(tenantID)`

**建议调用时机**：
- 客户跟进后
- 客户产生订单后
- 客户标签变化后

### 2. 全量重算

**接口**：`crm_score.RecalculateAll(tenantID)`

**耗时**：1 万客户约 5-10 秒。

**建议**：定时任务凌晨跑一次，避免工作时间阻塞。

### 3. 查看 Top 客户

**接口**：`crm_score.TopByScore(tenantID, 10)`

```json
{
  "tenant_id": "1",
  "limit": 10
}
```

返回按 score 降序的客户列表。

### 4. 工作台展示

工作台 → 客户管理 → 排序方式"按评分"。

## 评分的应用场景

| 场景 | 用途 |
|------|------|
| 客户列表排序 | 按 score 降序排列 |
| 工作台推荐 | Top 10 客户置顶 |
| 营销活动筛选 | 圈选高价值客户 |
| 销售业绩评估 | 高分客户数对比 |
| 自动分配 | 新客户优先分配给高分维护者（待实现） |

## 当前评分规则局限

1. **无配置化**：公式硬编码，无法可视化调整。
2. **维度偏少**：未考虑行业、地区、合作时长。
3. **无衰减**：老订单权重与新订单相同。
4. **无加权**：重要客户（VIP）无额外加成。

**产品补强方向**：
- 评分规则可配置（weight + dimension）
- 衰减因子（最近 N 天权重更高）
- 客户群对比（不同行业不同基准）

## 与 AI 洞察的区别

| 维度 | 评分（CrmScore） | AI 洞察（CrmAiAnalysis） |
|------|------------------|--------------------------|
| 实现 | 规则加权 | 规则统计（非 LLM） |
| 输出 | 0-100 分数 | 摘要 + 多维数据 |
| 频率 | 实时 | 按需 |
| 维度 | 4 项 | 跟进 + 消费 + 活动 |

## 注意事项

- **分数私有**：建议仅本人 + 主管可见，避免排名引发恶性竞争。
- **分数波动**：每次重算可能变化，建议有"评分历史"表。
- **AI 升级路径**：未来接入 LLM 后，用 AI 评分（语义理解）。
