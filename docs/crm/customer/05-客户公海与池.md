# 客户公海与池

## 目的
防止客户沉淀在离职/消极销售手里，通过"公海回收 → 重新分配"保持销售资源流转。

## 入口
- 工作台 → 客户公海池
- 设置 → 公海规则配置

## 数据模型

### CrmCustomer 公海字段
- `pool_status` 0/1：是否在公海
- `pool_at`：进入公海时间

### CrmPoolRule（公海规则）
`models/crm.go` 内置：
- `recycle_days`：未跟进天数阈值（默认 30）
- `enabled`：是否启用自动回收

### CrmAutoAllocation（自动分配规则）
`models/crm.go`：
- 新建客户后自动分配给谁
- 按"部门轮询 / 抢单 / 指定"

## 操作步骤

### 1. 配置公海规则

**接口**：`crm_pool.SetRule`

```json
{
  "recycle_days": 30,
  "enabled": true
}
```

### 2. 查看公海池

**接口**：`crm_pool.ListPool(tenantID, keyword, pager)`

返回 `pool_status=1` 的客户列表。

### 3. 销售主动释放客户到公海

**接口**：`crm_pool.Recycle(tenantID, customerIDs)`

将客户 `pool_status=1, pool_at=now, owner_user_id=null`。

### 4. 自动回收（定时任务）

**接口**：`tasks/crm_automation.go AutoRecycleAll`

**触发**：每小时一次。

**逻辑**（`crm_pool.go AutoRecycle`）：

```sql
-- 1. 找超期未跟进的客户
SELECT c.* FROM crm_customer c
WHERE c.tenant_id = ? AND c.pool_status = 0 AND c.is_locked = false
  AND c.is_blacklist = false
  AND c.last_followup_at < (now() - recycle_days)
```

`last_followup_at` 来自 `CrmFollowup` 最新一条的 created_at。

### 5. 销售认领客户

**接口**：`crm_pool.Claim(tenantID, userID, customerIDs)`

```json
{
  "customer_ids": ["1001", "1002"]
}
```

**逻辑**：
- 把客户的 `pool_status=0, owner_user_id=userID, pool_at=null`
- 写 `CrmTransferLog`（type=pool_claim）

### 6. 客户再分配（销售间转移）

**接口**：`crm_transfer.Transfer`

```json
{
  "customer_ids": ["1001"],
  "to_user_id": "201",
  "reason": "我即将离职"
}
```

**日志**：`CrmTransferLog` 记录 from/to/时间/原因。

### 7. 离职继承

**接口**：`crm_inheritance.Execute`

```json
{
  "from_user_id": "201",
  "to_user_id": "305",
  "inherit_type": "resign",  // transfer(在职) / resign(离职)
  "remark": "李四离职，客户转给王五"
}
```

**继承范围**：客户的客户主档 + 商机 + 跟进 + 工单 + 订单（如未完成）一并归属到新销售。

## 客户状态流转图

```
                     ┌─────────────────┐
                     │   新建客户       │
                     └────────┬────────┘
                              │
                ┌─────────────┼─────────────┐
                ▼                           ▼
         ┌──────────┐                ┌──────────┐
         │ 销售在跟  │ ◄──认领────  │   公海池  │
         └────┬─────┘                └────▲─────┘
              │                            │
              │ 超期未跟(30天)             │
              │ 自动回收 OR                │ 主动释放
              │ 主动释放                   │ Recycle()
              └────────────────────────────┘
              │
              │ 转移/继承
              ▼
         ┌──────────┐
         │  新销售  │
         └──────────┘
```

## 注意事项

- **锁客防回收**：`is_locked=true` 的客户不进入自动回收。
- **黑名单不回收**：`is_blacklist=true` 客户不进公海（直接屏蔽）。
- **重要客户**：VIP/重点客户不自动入海。
- **批量认领**：单次建议 ≤ 50 个，避免数据库压力。
- **审计**：转移/继承操作均写入 `CrmTransferLog`，可查历史。
- **共享 ≠ 转移**：共享保留原归属，转移变更归属。
