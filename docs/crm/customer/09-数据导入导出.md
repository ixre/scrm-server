# 数据导入导出

## 目的
批量迁移客户数据（从 Excel/旧 CRM）、备份当前客户库。

## 入口
- 工作台 → 客户管理 → 导入/导出

## 数据模型
- 无独立模型，直接读写 `CrmCustomer` + `ChannelLink`

## 操作步骤

### 1. 导出客户

**接口**：`crm_customer.Export`

**导出列**（`services/crm.go:971-1001`）：

```
ID, 姓名, 手机号, 邮箱, 公司, 行业, 等级, 来源, 归属销售,
下次跟进时间, 标签, 创建时间, 最后跟进时间, 备注
```

**生成**：服务端生成 .xlsx 文件，存对象存储，返回下载 URL。

### 2. 批量导入

**接口**：`crm_customer.BatchImport`

**导入列**（硬编码，`crm.go:1004-1036`）：

```
name, mobile, company
```

**限制**：
- 一次最多 1000 条
- 按 mobile 去重（已存在跳过）
- 不支持自定义字段映射（**产品补强点**）

### 3. 通过数据导出任务导出

**接口**：`data_export.GenDataExportTask`

```json
{
  "entity_type": "customer",
  "filter": {
    "owner_user_id": "201"
  },
  "format": "xlsx"
}
```

**异步任务**：

```
生成数据 → 写入对象存储 → 发通知 → 用户下载
```

支持大规模数据导出。

## 注意事项

- **脱敏**：当前导出**无脱敏**，手机号裸出。建议加"导出脱敏"开关。
- **字段映射**：批量导入硬编码 name/mobile/company 三字段，建议改成可视化映射。
- **重复处理**：导入时按 mobile 去重，已存在则跳过（非更新）。
- **性能**：1000 条以上建议用异步任务。
- **权限**：仅管理员可批量导入，普通销售无权限。
- **审计**：导入/导出建议记审计日志。

## 数据备份策略

| 方式 | 时机 |
|------|------|
| 自动全量备份 | 每天凌晨 03:00 |
| 增量备份 | 每小时（基于 updated_at） |
| 手动导出 | 管理员触发 |

**存储**：OSS/COS，独立 Bucket。
