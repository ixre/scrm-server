# 客户标签与自动打标

## 目的
通过标签实现客户精细化分群，驱动营销/销售自动化。

## 入口
- 客户管理 → 客户标签 → 客户标签
- 客户管理 → 客户标签 → 自动打标签

## 数据模型

### CrmChannelTag（渠道标签）
定义系统预设的渠道维度标签。`models/crm.go:303-313`：

```go
type CrmChannelTag struct {
    TenantID    string  // 租户
    Channel     string  // wecom/xiaohongshu/gzh/douyin
    Name        string  // 标签名
    Color       string  // 显示色
    Sort        int     // 排序
}
```

**预置种子**（`CrmChannelTagSeed`）：
- wecom：意向客户/已成交/已流失/高价值
- xiaohongshu：种草/收藏/咨询/已购
- gzh：关注/留言/已购/粉丝
- douyin：互动/粉丝/留言/已购

### 客户标签（`CrmCustomer.Tags`）
JSONB 字段，存的是 `CrmChannelTag.ID` 数组。

### CrmAutoTagRule（自动打标规则）
`models/crm.go:543-555`：

| 字段 | 说明 |
|------|------|
| `name` | 规则名 |
| `trigger_type` | interaction_count / order_amount / has_followup |
| `trigger_cond` | 条件（如 `>=3`） |
| `tag_name` | 要打的标签名 |
| `channel` | 限定渠道（空 = 不限） |
| `status` | active / disabled |

## 操作步骤

### 1. 创建渠道标签

**接口**：`crm_channel_tag.Create`

```json
{
  "channel": "wecom",
  "name": "VIP客户",
  "color": "#FF0000"
}
```

**注意**：同渠道同租户下标签名唯一。

### 2. 列出渠道标签

**接口**：`crm_channel_tag.List`

```json
{
  "channel": "wecom"
}
```

返回按 sort 升序的列表。

### 3. 给客户打标签

**接口**：`crm_customer.Update`（修改 `tags` 字段）

或前端批量选择标签后调用 `crm_batch.Execute` 批量打标。

### 4. 创建自动打标规则

**接口**：`crm_auto_tag.CreateRule`

```json
{
  "name": "互动≥10次自动打高价值",
  "trigger_type": "interaction_count",
  "trigger_cond": ">=10",
  "tag_name": "高价值",
  "channel": ""
}
```

### 5. 列出规则

**接口**：`crm_auto_tag.QueryRules`

### 6. 启用/停用规则

**接口**：`crm_auto_tag.DeleteRules`（硬删）

或直接 Update status 字段。

### 7. 手动触发

**接口**：`crm_auto_tag.ApplyToCustomer(tenantID, customerID)`

**用途**：新客户创建后立即触发一次规则评估。

### 8. 全量扫描

**接口**：`crm_auto_tag.ApplyAll(tenantID)`（内部定时任务方法，未在 dispatch 注册）

**定时任务**：`tasks/crm_automation.go` 每小时跑一次。

## 触发器详解（`crm_auto_tag.go matchRule`）

| trigger_type | 含义 | trigger_cond 格式 |
|--------------|------|------------------|
| `interaction_count` | 渠道互动次数 | `>=N` |
| `order_amount` | 累计订单金额 | `>=N`（单位元） |
| `has_followup` | 有无跟进 | 无需条件 |

**匹配逻辑**：

```go
switch rule.TriggerType {
case "interaction_count":
    cnt := CrmChannelInteraction.Count
    return cnt >= parseThreshold(cond)
case "order_amount":
    sum := SUM(CrmOrder.amount WHERE status IN signed,completed)
    return sum >= parseThreshold(cond)
case "has_followup":
    return CrmFollowup.Count > 0
}
```

## 注意事项

- **渠道标签 ≠ 内部标签**：渠道标签是渠道侧的能力（企微/小红书/抖音都各有自己的标签），自动打标通过渠道标签统一管理。
- **触发器有限**：当前仅 3 种触发器，覆盖不到"加入群聊→自动打标""生日→VIP"等场景（产品路线图补强点）。
- **规则执行频率**：全量扫描每小时一次，非实时。建议新客户用 `ApplyToCustomer` 立即触发。
- **打标去重**：已存在的标签不再重复添加（避免 UPDATE 全部 tags）。
