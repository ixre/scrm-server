# 发票

## 目的
发票申请、审核、开具、归档。

## 入口
- 工作台 → 财务管理 → 发票管理

## 数据模型

### Invoice（发票）

| 字段 | 说明 |
|------|------|
| `invoice_type` | vat_special / vat_general / electronic |
| `title` | 发票抬头 |
| `tax_no` | 税号 |
| `amount` | 金额 |
| `tax_rate` | 税率 |
| `tax_amount` | 税额 |
| `order_id` | 关联订单 |
| `status` | pending / issued / cancelled |
| `invoice_no` | 发票号码 |
| `issued_at` | 开具时间 |

## 操作步骤

### 1. 申请发票

**接口**：`invoice.Apply`

```json
{
  "invoice_type": "vat_special",
  "title": "Acme 公司",
  "tax_no": "91310115MA1K3DXXXX",
  "amount": 10000,
  "order_id": "ORD20260818001",
  "address": "上海市浦东新区...",
  "phone": "021-12345678",
  "bank": "招行上海分行",
  "account": "1234 5678 9012"
}
```

### 2. 审核发票

**接口**：`invoice.Approve / Reject`

### 3. 标记已开

**接口**：`invoice.MarkIssued(invoice_no, pdf_url)`

上传发票 PDF 到 OSS，记录发票号。

### 4. 红冲发票

**接口**：`invoice.RedReverse(reason)`

生成红字发票，记录负数金额。

## 发票类型

| 类型 | 适用 | 税率 |
|------|------|------|
| 增值税专用发票 | 一般纳税人 | 13% / 9% / 6% |
| 增值税普通发票 | 小规模 | 3% |
| 电子发票 | 通用 | 同上 |

## 注意事项

- **税率校验**：根据商品类型适用税率。
- **金额校验**：发票金额 ≤ 订单已回款金额。
- **税号校验**：税号格式校验（15/18/20 位）。

## 当前限制（**产品补强点**）

- 未对接税务系统（金税系统）自动开票。
- 无发票批量开具。
