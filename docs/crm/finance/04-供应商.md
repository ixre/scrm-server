# 供应商

## 目的
供应商档案管理 + 采购订单。

## 入口
- 销售管理 → 业务扩展 → 供应商

## 数据模型

### Supplier（供应商）

| 字段 | 说明 |
|------|------|
| `name` | 供应商名 |
| `contact_person` | 联系人 |
| `phone` / `email` | 联系方式 |
| `address` | 地址 |
| `tax_no` | 税号 |
| `bank_info` | 开户行/账号 |
| `category` | 分类（原料/服务/设备） |
| `status` | active / inactive / blacklisted |

### PurchaseOrder（采购单）

| 字段 | 说明 |
|------|------|
| `supplier_id` | 供应商 |
| `items` | 商品明细 JSON |
| `total_amount` | 总金额 |
| `status` | pending / approved / received / paid / cancelled |
| `received_at` | 到货时间 |
| `paid_at` | 付款时间 |

## 操作步骤

### 1. 创建供应商

**接口**：`crm_supplier.Create`

### 2. 创建采购单

**接口**：`crm_purchase_order.Create`

```json
{
  "supplier_id": "200",
  "items": [
    {"product_id": "100", "quantity": 1000, "unit_price": 50}
  ]
}
```

### 3. 采购审批

**触发**：金额 > 阈值 → `approval.Submit(biz_type=purchase)`

### 4. 到货入库

**接口**：`crm_purchase_order.ChangeStatus`

```go
1. 状态置 received
2. 自动触发 InventoryIn（每个商品入库）
3. 记录到货时间
```

### 5. 付款

**接口**：`purchase.Pay`（**未在 dispatch 注册**）

```go
1. 创建 FinanceRecord(type=expense, category=采购付款)
2. 状态置 paid
3. 记录付款时间
```

## 供应商评级（**产品补强点**）

**当前未实现**：
- 按时到货率
- 质量合格率
- 价格优势

## 注意事项

- **黑名单**：status=blacklisted 的供应商不可新建采购单。
- **税号唯一**：同一供应商税号唯一。
- **跨租户禁止**。

## 当前限制（**产品补强点**）

- 无供应商评级。
- 无询价/比价流程。
- 无供应商对账。
