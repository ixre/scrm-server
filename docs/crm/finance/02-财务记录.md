# 财务记录

## 目的
记录收入、支出、转账等资金流水。

## 入口
- 销售管理 → 业务扩展 → 财务管理

## 数据模型

### FinanceRecord（财务流水）

| 字段 | 说明 |
|------|------|
| `type` | income / expense / transfer |
| `category` | 分类（订单回款/采购付款/工资/报销） |
| `amount` | 金额 |
| `biz_type` | 关联业务（order / purchase / expense） |
| `biz_id` | 业务对象 ID |
| `account` | 账户（对公/微信/支付宝） |
| `occurred_at` | 发生时间 |
| `remark` | 备注 |

## 操作步骤

### 1. 收入记账

**触发**：订单回款入账

```go
order.received(amount):
  FinanceRecord.Create(
    type=income,
    category=订单回款,
    amount=amount,
    biz_type=order,
    biz_id=order_id,
    account=对公账户,
  )
```

### 2. 支出记账

**触发**：采购付款、报销、工资

```go
purchase.paid():
  FinanceRecord.Create(
    type=expense,
    category=采购付款,
    amount=amount,
    biz_type=purchase,
    ...
  )
```

### 3. 转账

**接口**：`crm_fund_transfer.Create(fromAccount, toAccount, amount)`

生成 2 条流水（转出/转入）。

### 4. 月度报表

**接口**：`finance.MonthlyReport(year, month)`（**未在 dispatch 注册**）

```json
{
  "income_total": 100000,
  "expense_total": 60000,
  "profit": 40000,
  "by_category": {
    "订单回款": 80000,
    "其他收入": 20000
  }
}
```

## 账户管理

| 账户类型 | 说明 |
|----------|------|
| 对公账户 | 企业银行账户 |
| 微信 | 微信收款 |
| 支付宝 | 支付宝 |
| 现金 | 现金 |

## 注意事项

- **不可修改**：财务记录创建后**不允许修改**（审计要求），错误需红冲。
- **红冲**：通过创建相反流水实现。
- **跨租户禁止**。

## 当前限制（**产品补强点**）

- 无银行流水对账（需导入银行流水比对）。
- 无预算管理。
- 无多币种。
