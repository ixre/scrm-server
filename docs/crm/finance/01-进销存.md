# 进销存

## 目的
商品库存管理，支持出入库、盘点、库存预警。

## 入口
- 销售管理 → 业务扩展 → 进销存

## 数据模型

### Product（商品）

| 字段 | 说明 |
|------|------|
| `name` | 商品名 |
| `sku` | SKU |
| `category` | 分类 |
| `unit` | 单位 |
| `price` | 售价 |
| `cost` | 成本 |
| `status` | active / inactive |

### Inventory（库存）

| 字段 | 说明 |
|------|------|
| `product_id` | 商品 |
| `warehouse_id` | 仓库 |
| `quantity` | 数量 |
| `locked_quantity` | 锁定数量 |
| `safety_stock` | 安全库存 |

### InventoryIn（入库）

| 字段 | 说明 |
|------|------|
| `product_id` | 商品 |
| `quantity` | 数量 |
| `unit_cost` | 单位成本 |
| `supplier_id` | 供应商 |
| `operator_id` | 经办人 |
| `in_at` | 入库时间 |

### InventoryOut（出库）

| 字段 | 说明 |
|------|------|
| `product_id` | 商品 |
| `quantity` | 数量 |
| `order_id` | 关联订单 |
| `out_at` | 出库时间 |

## 操作步骤

### 1. 创建商品

**接口**：`crm_product.Create`

### 2. 采购入库

**接口**：`crm_stock_in.Create`

```json
{
  "product_id": "100",
  "quantity": 1000,
  "unit_cost": 50,
  "supplier_id": "200"
}
```

**逻辑**：

```go
1. 校验商品存在
2. 创建 InventoryIn
3. Inventory.quantity += quantity
4. 触发库存预警检查（quantity > safety_stock?）
```

### 3. 销售出库

**触发**：订单状态从 pending → paid

**逻辑**：

```go
1. order.paid() 触发
2. 创建 InventoryOut
3. Inventory.quantity -= order.quantity
4. 触发预警检查（quantity < safety_stock? → 补货提醒）
```

### 4. 库存盘点

**接口**：`crm_stock_check.Create`

```json
{
  "warehouse_id": "1",
  "items": [
    {"product_id": "100", "actual_quantity": 950, "system_quantity": 1000, "diff": -50}
  ]
}
```

系统生成盘盈/盘亏记录。

### 5. 库存预警

**定时任务**：

```go
每天扫描 Inventory：
  if quantity < safety_stock:
    notify staff + 触发采购申请
```

## 注意事项

- **并发锁**：库存扣减用乐观锁 `WHERE quantity >= ?`，防止超卖。
- **批次管理**：是否支持批次/有效期？**当前未实现**。
- **多仓库**：当前支持多 warehouse，**已实现**。

## 当前限制（**产品补强点**）

- 无多单位（件/箱/kg）。
- 无序列号/SKU 维度的批次管理。
- 无库位管理。
