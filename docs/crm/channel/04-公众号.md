# 公众号

## 目的
公众号（订阅号/服务号）作为内容渠道，覆盖关注、菜单、模板消息。

## 入口
- 工作台 → 系统设置 → 渠道接入 → 公众号
- 配置 app_id / app_secret

## 接入准备

1. 微信公众平台注册
2. 订阅号（个人）或服务号（企业）
3. 获取 app_id / app_secret
4. 配置服务器 URL（用于接收事件）
5. 配置业务域名、JS 安全域名

## 数据模型

### CrmChannelLink (channel=gzh)

| 字段 | 说明 |
|------|------|
| `customer_id` | 本地客户 ID |
| `channel` | gzh |
| `channel_user_id` | openid（公众号内） |
| `channel_union_id` | unionid（开放平台下唯一） |
| `nickname` | 微信昵称 |
| `avatar` | 头像 |

公众号侧用 openid 作为用户标识，**unionid 在跨公众号/小程序时统一**。

### 公众号关注记录
存储在 `CrmChannelLink` + 公众号事件记录：

| 事件 | 说明 |
|------|------|
| subscribe | 关注 |
| unsubscribe | 取消关注 |
| scan | 扫码 |

### 菜单/模板消息

| 概念 | 说明 |
|------|------|
| 自定义菜单 | 公众号底部菜单 |
| 模板消息 | 业务通知（服务号独有） |
| 客服消息 | 48h 内回复（订阅号可用） |

## 操作步骤

### 1. 客户关注接入

**触发**：用户扫码 / 搜索关注公众号

**回调处理**：`services/crm_gzh_douyin.go`：

```go
1. 接收公众号回调（event=subscribe）
2. 解析 openid + unionid
3. 拉取用户信息（GetUserInfo via access_token）
4. 查 CrmChannelLink (channel=gzh, channel_user_id=openid)
   ├── 找到 → 更新关注时间
   └── 找不到 → 创建 CrmCustomer + CrmChannelLink (is_primary=false)
```

### 2. 模板消息发送

**接口**：`dispatch.Send(ChannelGzh, openid, templateMsg)`

**示例**：

```json
{
  "template_id": "abc123",
  "data": {
    "first": {"value": "您的订单已发货"},
    "orderNo": {"value": "ORD20260818001"},
    "remark": {"value": "点击查看详情"}
  },
  "url": "https://example.com/order/123"
}
```

**限制**：服务号每月 10 万条免费额度，超出需付费。

### 3. 菜单管理

**接口**：`crm_gzh.CreateMenu / GetMenu / DeleteMenu`

```json
{
  "button": [
    {
      "name": "产品",
      "sub_button": [
        {"type": "view", "name": "H5 商城", "url": "https://..."},
        {"type": "click", "name": "联系客服", "key": "contact_cs"}
      ]
    }
  ]
}
```

### 4. 客服消息

**限制**：仅在用户主动发起对话 48 小时内可发送。

**接口**：`dispatch.Send(ChannelGzh, openid, content)`

### 5. 扫码带参数

公众号支持生成带参数的二维码：

**接口**：`crm_gzh.CreateQRCode(sceneID)`

```
用户扫码 → 回调 event=scan, sceneID=xxx
        │
        ▼
根据 sceneID 识别扫码场景（渠道活码/活动）
```

## 公众号特有功能

| 功能 | 说明 |
|------|------|
| 关注自动回复 | 关注后立即发欢迎语 |
| 关键词回复 | 文本消息命中关键词触发 |
| 模板消息 | 服务号通知（订单/发货） |
| 网页授权 | 静默/用户授权获取 openid |
| 卡券 | 微信卡券（**当前未实现**） |

## 当前已知问题

- **模板消息额度**：服务号每月 10 万条（按 appid），**超额需付费**。
- **48h 限制**：客服消息严格 48h，**超限需用模板消息**。
- **网页授权**：需配置 JS 安全域名 + 网页授权域名。

## 注意事项

- **access_token 刷新**：2h 过期，公众号 + 全局 token 各 1 个。
- **unionid**：仅在微信开放平台下绑定的多个公众号/应用才能拿到 unionid。
- **消息加密**：公众号回调消息需用 aes 加密。

## 当前限制（**产品补强点**）

- 无卡券（微信卡券体系）。
- 无图文素材管理。
- 无菜单点击统计。
