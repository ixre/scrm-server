# 小红书

## 目的
小红书作为种草内容渠道，覆盖私信/笔记互动场景。

## 入口
- 客户管理 → 引流获客
- 配置 client_id / client_secret

## 接入准备

1. 小红书开放平台注册开发者账号
2. 创建应用，获取 client_id / client_secret
3. 配置 OAuth 回调 URL
4. 申请接口权限（私信 / 笔记）

## 数据模型

### CrmChannelLink (channel=xiaohongshu)

| 字段 | 说明 |
|------|------|
| `customer_id` | 本地客户 ID |
| `channel` | xiaohongshu |
| `channel_user_id` | 小红书 user_id |
| `nickname` | 小红书昵称 |
| `avatar` | 头像 |
| `red_id` | 小红书号（用户唯一标识） |

### CrmChannelInteraction

小红书的笔记互动/私信都存在 `CrmChannelInteraction`：

`models/crm.go:250-262`：

| 字段 | 说明 |
|------|------|
| `customer_id` | 客户 |
| `channel` | xiaohongshu |
| `interaction_type` | note_like / note_comment / note_collect / private_msg |
| `target_id` | 笔记/私信 ID |
| `content` | 内容 |
| `interacted_at` | 互动时间 |

## 操作步骤

### 1. 客户私信触发接入

**触发**：客户在笔记下评论或主动私信

**回调处理**：`services/crm_xhs.go`：

> ⚠️ 以下 `crm_xhs.*` 接口均**未在 dispatch 注册（内部服务方法）**。

```go
1. 接收小红书回调（私信消息 / 评论事件）
2. 解析 sender_id（小红书 user_id）
3. 拉取用户信息（GetUserInfo）
4. 查 CrmChannelLink (channel=xiaohongshu, channel_user_id=sender_id)
   ├── 找到 → 关联现有客户
   └── 找不到 → 创建 CrmCustomer + CrmChannelLink
```

### 2. 笔记互动追踪

**接口**：`crm_xhs.TrackInteraction`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

```go
记录点赞 / 评论 / 收藏 到 CrmChannelInteraction：
- interaction_type=note_like/comment/collect
- target_id=笔记 ID
- 触发 SOP（如有）
```

### 3. 私信回复

**接口**：`dispatch.Send(ChannelXiaohongshu, redID, content)`

支持的消息类型：
- text（文本）
- image（图片）
- card（卡片）

### 4. 笔记同步（可选）

**接口**：`crm_xhs.ListNotes`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

拉取我方账号发布的笔记，用于销售在客户画像展示"共同关注"。

### 5. 客户标签同步

**接口**：`crm_xhs.TagCustomer(redID, tags)`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

小红书侧标签 + 本地 `CrmCustomerTag` 同步。

## 小红书特有功能

| 功能 | 说明 |
|------|------|
| 私信自动回复 | 关键词触发 |
| 评论区运营 | 自动回复 / 私信跳转 |
| 笔记��送 | 给关注用户发私信（需权限） |
| 粉丝画像 | 拉取粉丝数据（**部分接口受限**） |

## 当前已知问题

- **接口权限**：私信接口需"品牌合作人"资质，**门槛较高**。
- **频控**：小红书 API 频控较严，**当前未实现频控**。
- **消息延迟**：私信回调可能延迟 1-2 秒。

## 注意事项

- **OAuth scope**：私信需 `msg_send` scope，需用户授权。
- **content moderation**：小红书对私信内容有敏感词审查。
- **小红书号**：redID 是用户唯一标识，比 user_id 更稳定。

## 当前限制（**产品补强点**）

- 无笔记内容分析（仅追踪互动，不分析笔记内容）。
- 无直播间接入（小红书直播暂未开放 API）。
