# 企业微信

## 目的
企业微信（企微）作为最重要的私域渠道，覆盖好友/群/消息等核心场景。

## 入口
- 客户管理 → 引流获客 → 渠道活码
- 配置 corp_id / corp_secret / agent_id

## 接入准备

1. 企业微信管理后台创建应用
2. 获取 corp_id（企业 ID）
3. 获取 corp_secret（应用 Secret）
4. 配置回调 URL（用于接收事件）
5. 配置可信域名

## 数据模型

### 企微客户（external_userid）
企微侧的"外部联系人" ID，**不是本地主键**。

### CrmChannelLink (channel=wecom)

| 字段 | 说明 |
|------|------|
| `customer_id` | 本地客户 ID |
| `channel` | wecom |
| `channel_user_id` | external_userid |
| `channel_union_id` | unionid（跨企业） |
| `nickname` | 企微昵称 |
| `avatar` | 头像 |
| `is_primary` | 是否主渠道 |

### CrmWecomGroup（企微客户群）

`models/crm.go:1300-`：

| 字段 | 说明 |
|------|------|
| `group_id` | 企微群 chat_id |
| `name` | 群名 |
| `owner_id` | 群主员工 |
| `member_count` | 成员数 |

### CrmWecomMessage（企微消息）

`models/crm.go:1350-`：

| 字段 | 说明 |
|------|------|
| `msg_id` | 企微消息 ID |
| `from_user` | 发送者 external_userid |
| `to_user` | 接收者 |
| `msg_type` | text / image / file / event |
| `content` | 消息内容 |
| `direction` | inbound / outbound |
| `sent_at` | 发送时间 |

## 操作步骤

### 1. 添加好友（外部联系人添加）

**触发**：客户扫员工活码 / 员工搜索手机号添加

**回调处理**：`crm_wecom.HandleAddContact`（`services/crm_wecom.go`）

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

```go
1. 接收企微回调（event=change_external_contact, change_type=add_external_contact）
2. 解析 external_userid + userid
3. 拉取详情（GetUserInfo → nickname/avatar/unionid）
4. 查 CrmChannelLink (channel=wecom, channel_user_id=external_userid)
   ├── 找到 → 关联到现有客户
   └── 找不到 → 创建 CrmCustomer + CrmChannelLink
```

### 2. 客户消息收发

**入站**：企微回调 → `crm_wecom.HandleMessage` → 存 `CrmWecomMessage` + 触发 SOP

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

**出站**：`dispatch.Send(ChannelWeCom, external_userid, content)`

支持的 `msg_type`：
- text（文本）
- image（图片）
- file（文件）
- video（视频）
- link（链接卡片）
- miniprogram（小程序）

### 3. 群管理

**创建群**：`crm_wecom.CreateGroup`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

**拉人进群**：`crm_wecom.AddToGroup(groupID, externalUserIDs)`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

**群消息**：`dispatch.SendGroup(ChannelWeCom, groupID, content)`

**群成员**：`crm_wecom.ListGroupMembers`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

### 4. 离职继承

**接口**：`crm_wecom.TransferOnLeave`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

```go
1. 员工离职事件触发
2. 调用企微 API：transfer_external_user / transfer_group
3. 重新分配 CrmCustomer.owner_id
4. 记录 CrmCustomerTransferLog
```

### 5. 标签管理（企微侧标签）

**接口**：`crm_wecom.TagCustomer(externalUserID, tagIDs)`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

写入企微侧标签 + 同步到本地 `CrmCustomerTag`。

## 企微特有功能

| 功能 | 说明 |
|------|------|
| 活码 | 群活码/员工活码，自动分流 |
| 欢迎语 | 客户添加后自动发欢迎语 |
| SOP | 群 SOP（见 14-群SOP.md） |
| 客户继承 | 员工离职后客户分配 |
| 会话存档 | 合规存档员工与客户会话（**当前未实现**） |
| 应用消息 | 通过自建应用发消息 |

## 当前已知问题

- **会话存档**：合规要求金融等行业必须存档，**当前未实现**（**待补强**）。
- **API 频率限制**：企微 6000 次/分钟，**当前未实现频控**。
- **unionid**：跨企业 unionid 需要客户授权，**覆盖率较低**。

## 注意事项

- **access_token 缓存**：2 小时过期，需定时任务刷新。
- **回调 URL 加密**：企微要求回调 URL 带 aeskey 加密。
- **可信 IP**：企微要求服务端 IP 在可信列表中。
- **多企业**：同一系统支持多企业微信接入（**当前架构支持但需配置多个 corp_id**）。
