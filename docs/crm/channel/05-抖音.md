# 抖音

## 目的
抖音作为短视频/直播渠道，覆盖私信、视频互动。

## 入口
- 客户管理 → 引流获客
- 配置 client_key / client_secret

## 接入准备

1. 抖音开放平台注册开发者账号
2. 创建应用（小程序/网站应用）
3. 获取 client_key / client_secret
4. 配置 OAuth 回调 URL
5. 申请接口权限（私信 / 视频）

## 数据模型

### CrmChannelLink (channel=douyin)

| 字段 | 说明 |
|------|------|
| `customer_id` | 本地客户 ID |
| `channel` | douyin |
| `channel_user_id` | 抖音 open_id |
| `nickname` | 抖音昵称 |
| `avatar` | 头像 |
| `douyin_id` | 抖音号 |

### CrmChannelInteraction

抖音视频互动：

| 字段 | 说明 |
|------|------|
| `interaction_type` | video_like / video_comment / video_share / private_msg |
| `target_id` | 视频 ID |

## 操作步骤

### 1. 私信接入

**触发**：客户在视频评论或主动私信

**回调处理**：`services/crm_gzh_douyin.go:233-`：

> ⚠️ 以下 `crm_douyin.*` 接口均**未在 dispatch 注册（内部服务方法）**。

```go
1. 接收抖音回调（私信事件）
2. 解析 sender open_id
3. 拉取用户信息
4. 查 CrmChannelLink (channel=douyin, channel_user_id=open_id)
   ├── 找到 → 关联现有客户
   └── 找不到 → 创建 CrmCustomer + CrmChannelLink
```

### 2. 视频互动追踪

**接口**：`crm_douyin.TrackInteraction`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

记录点赞 / 评论 / 分享 到 CrmChannelInteraction。

### 3. 私信回复

**接口**：`dispatch.Send(ChannelDouyin, openID, content)`

支持：
- text
- image
- video
- card

### 4. 视频列表

**接口**：`crm_douyin.ListVideos`

> ⚠️ **未在 dispatch 注册（内部服务方法）**。

拉取我方账号视频列表，用于在客户画像展示。

### 5. 直播间接入

**当前未实现**（**产品补强点**）：抖音直播间弹幕/私信未接入。

## 抖音特有功能

| 功能 | 说明 |
|------|------|
| 短视频互动 | 点赞/评论/分享追踪 |
| 私信自动回复 | 关键词触发 |
| 评论运营 | 自动回复评论 |
| 直播弹幕 | **未实现** |

## 当前已知问题

- **API 权限**：私信接口需"客户服务"权限。
- **频控**：抖音 API 频控较严。
- **live 接入**：直播相关 API 需单独申请。

## 注意事项

- **OAuth scope**：私信需 `im.message.send` scope。
- **抖音号 vs open_id**：open_id 是抖音侧唯一标识，抖音号是用户可改的对外号。
- **私信敏感词**：抖音侧有内容审查。

## 当前限制（**产品补强点**）

- 无直播间接入。
- 无视频内容分析。
- 无粉丝画像。
