# 渠道统计

## 目的
对比多渠道获客/转化效果，指导资源投放。

## 入口
- 销售管理 → 数据分析

## 核心指标

### 获客指标

| 指标 | 计算 | 数据源 |
|------|------|--------|
| 新增客户数 | count(CrmCustomer WHERE channel=? AND created_at BETWEEN) | CrmCustomer |
| 新增客户数（按渠道） | count(CrmChannelLink WHERE channel=?) | CrmChannelLink |
| 获客成本 | 广告投放金额 / 新增客户数 | 外部导入 |

### 活跃指标

| 指标 | 计算 | 数据源 |
|------|------|--------|
| 互动数 | count(CrmChannelInteraction WHERE channel=?) | CrmChannelInteraction |
| 私信数 | count(CrmWecomMessage WHERE direction=inbound) | CrmWecomMessage |
| 群消息数 | count(group messages) | group_messages |

### 转化指标

| 指标 | 计算 |
|------|------|
| 加好友 → 下单率 | count(order) / count(add_external_contact) |
| 互动 → 加好友率 | count(add_contact) / count(interaction) |
| 渠道成单 GMV | sum(order.amount WHERE customer.channel=?) |

## 接口

### 1. 渠道汇总

**接口**：`crm_report.ChannelSummary(tenantID, dateRange)`

```json
{
  "rows": [
    {
      "channel": "wecom",
      "new_customers": 100,
      "interactions": 5000,
      "orders": 50,
      "gmv": 100000
    },
    {
      "channel": "xiaohongshu",
      "new_customers": 80,
      "interactions": 3000,
      "orders": 30,
      "gmv": 50000
    }
  ]
}
```

`services/crm.go:1602 ChannelSummary` 已实现。

### 2. 渠道对比

**接口**：`crm_report.ChannelCompare(tenantID, dimension, dateRange)`

`dimension`：
- new_customers（新增客户数）
- gmv（销售额）
- interaction（互动数）
- conversion（转化率）

`services/crm.go:1664 ChannelCompare` 已实现。

### 3. 渠道漏斗

```go
曝光（landing）──► 互动（comment/like）──► 加好友 ──► 下单
     │                    │                    │           │
     ▼                    ▼                    ▼           ▼
   100%               80%                 30%           5%
```

### 4. 跨渠道客户旅程

**接口**：`crm_report.CustomerJourney(customerID)`

> ⚠️ **未在 dispatch 注册**（dispatch 仅注册 SalesSummary/PipelineFunnel/ChannelSummary/ChannelCompare/ActivityFunnel/SalesRanking/CustomerLifecycle/ChannelCAC）。

返回客户在每个渠道的触点时间线：

```
2026-08-10 公众号关注
2026-08-12 小红书私信
2026-08-15 加企微好友
2026-08-18 下单
```

## 数据来源

| 表 | 用法 |
|----|------|
| `CrmCustomer` | 客户来源 channel 字段 |
| `CrmChannelLink` | 渠道 + 关注时间 |
| `CrmChannelInteraction` | 互动 |
| `CrmWecomMessage` | 企微消息 |
| `CrmOrder` | 订单 |
| `CrmActivityRecord` | 活动参与 |

## 注意事项

- **去重**：跨渠道客户去重，避免重复统计。
- **首次来源**：用 `CrmCustomer.created_at` + `channel` 标记首次来源。
- **跨渠道成交**：客户在小红书加好友 + 在企微成交，**应归到主渠道**。

## 当前限制（**产品补强点**）

- 无获客成本统计（需对接广告平台）。
- 无渠道 ROI（投产比）。
- 无实时看板（**T+1 为主**）。
