# 公告知识库

## 目的
公司公告发布 + 内部知识库（Wiki）。

## 入口
- 销售管理 → 业务扩展 → 办公OA

## 数据模型

### Announcement（公告）

| 字段 | 说明 |
|------|------|
| `title` | 标题 |
| `content` | 内容（富文本） |
| `category` | 分类（通知/活动/制度） |
| `level` | 重要程度（normal / important / urgent） |
| `publisher_id` | 发布人 |
| `published_at` | 发布时间 |
| `expire_at` | 过期时间 |
| `read_count` | 已读数 |

### AnnouncementRead（已读记录）

| 字段 | 说明 |
|------|------|
| `announcement_id` | 公告 |
| `staff_id` | 员工 |
| `read_at` | 阅读时间 |

### KnowledgeArticle（知识库文章）

| 字段 | 说明 |
|------|------|
| `title` | 标题 |
| `content` | 内容 |
| `category` | 分类（产品/销售/技术） |
| `tags` | 标签 |
| `author_id` | 作者 |
| `view_count` | 浏览数 |
| `like_count` | 点赞数 |

## 操作步骤

### 1. 发布公告

**接口**：`crm_notice.Create`

```json
{
  "title": "8 月 18 日系统维护通知",
  "content": "今晚 22:00 - 23:00 系统维护",
  "category": "通知",
  "level": "important",
  "expire_at": "2026-08-19"
}
```

### 2. 标记已读

**接口**：`announcement.MarkRead(announcementID)`（**未在 dispatch 注册**）

```go
1. 创建/更新 AnnouncementRead (read_at=now)
2. announcement.read_count += 1
```

### 3. 未读提醒

**接口**：`announcement.UnreadFor(staffID)`（**未在 dispatch 注册**）

返回该员工所有未读公告。

### 4. 创建知识库文章

**接口**：`crm_knowledge.Create`

支持富文本编辑器（图片/代码块/表格）。

### 5. 搜索知识库

**接口**：`knowledge.Search(keyword)`（**未在 dispatch 注册**）

全文搜索（**当前为 LIKE 查询，**未集成 ES**）。

### 6. 文章点赞/收藏

**接口**：`knowledge.Like / Favorite`（**未在 dispatch 注册**）

## 知识库分类

| 分类 | 示例 |
|------|------|
| 产品文档 | 产品手册、FAQ |
| 销售话术 | 行业话术集 |
| 培训资料 | 新人手册 |
| 公司制度 | 规章制度 |
| 技术文档 | API 文档 |

## 注意事项

- **公告置顶**：`level=urgent` 自动置顶。
- **已读未读**：根据 AnnouncementRead 判定。
- **过期清理**：定时任务清理过期公告（**当前未实现自动清理**）。

## 当前限制（**产品补强点**）

- 无全文搜索引擎（ES/Meilisearch）。
- 无文章版本历史。
- 无文章评论。
