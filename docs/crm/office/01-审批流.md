# 审批流

## 目的
通用审批引擎，覆盖请假/报销/折扣/合同等业务审批。

## 入口
- 企业管理 → 系统设置 → 审批引擎

## 数据模型

### Approval（审批单）

| 字段 | 说明 |
|------|------|
| `biz_type` | 业务类型（leave / expense / discount / contract） |
| `biz_id` | 业务对象 ID |
| `applicant_id` | 申请人 |
| `title` | 审批标题 |
| `content` | 审批内容/理由 |
| `status` | pending / approved / rejected / withdrawn |
| `current_node` | 当前节点 |

### ApprovalFlow（审批流模板）

| 字段 | 说明 |
|------|------|
| `name` | 流程名 |
| `biz_type` | 业务类型 |
| `nodes` | 节点 JSON：[{name, type, approver, condition}] |

### ApprovalLog（审批日志）

| 字段 | 说明 |
|------|------|
| `approval_id` | 审批单 |
| `node_name` | 节点 |
| `approver_id` | 审批人 |
| `action` | approve / reject / transfer |
| `comment` | 意见 |
| `acted_at` | 处理时间 |

## 操作步骤

### 1. 创建审批流模板

**接口**：`crm_approval_flow.Create`

```json
{
  "name": "折扣审批流",
  "biz_type": "discount",
  "nodes": [
    {"name": "销售经理", "approver": "sales_manager"},
    {"name": "销售总监", "approver": "sales_director", "condition": "amount > 10000"},
    {"name": "财务", "approver": "finance", "condition": "amount > 50000"}
  ]
}
```

### 2. 发起审批

**接口**：`crm_approval.Submit`

```json
{
  "biz_type": "discount",
  "biz_id": "order_100",
  "title": "订单 ORD20260818001 申请 9 折",
  "content": "客户为 VIP，年度合作客户"
}
```

### 3. 审批/拒绝

**接口**：`crm_approval.Approve` / `crm_approval.Reject`

```json
{
  "approval_id": "1001",
  "comment": "同意"
}
```

### 4. 转交

**接口**：`approval.Transfer(toUserID)`（**未在 dispatch 注册**）

### 5. 撤回

**接口**：`crm_approval.Void`

仅申请人本人可撤回，状态为 pending 时有效。

## 审批流引擎

```go
// services/approval.go:ProcessApproval
func ProcessApproval(approvalID) {
    flow := LoadFlow(approval.biz_type)
    currentNode := flow.Nodes[approval.current_node]
    
    if approval.action == approve {
        if currentNode.condition(approval) {
            approval.current_node += 1
            if approval.current_node >= len(flow.Nodes) {
                approval.status = approved
                OnApproved(approval)  // 回调业务
            }
        }
    }
}
```

## 业务集成

| biz_type | 触发 |
|----------|------|
| `leave` | 考勤请假提交 |
| `expense` | 报销提交 |
| `discount` | 订单申请折扣 |
| `contract` | 合同审批 |
| `workorder` | 大额工单审批 |

**回调机制**：审批通过后调用业务侧 `OnApproved` 完成业务变更。

## 注意事项

- **条件节点**：使用 `condition` 字段动态决定是否进入某节点。
- **会签/或签**：当前实现是顺序审批，**会签/或签需扩展**。
- **审批时效**：超时未审批的催办机制（**当前未实现**）。

## 当前限制（**产品补强点**）

- 无并行会签。
- 无审批委派（代理人）。
- 无审批加签。
