# 工作报告

## 目的
员工日报/周报/月报提交，沉淀工作记录。

## 入口
- 销售管理 → 业务扩展 → 办公OA

## 数据模型

### WorkReport

| 字段 | 说明 |
|------|------|
| `staff_id` | 员工 |
| `type` | daily / weekly / monthly |
| `period_start` / `period_end` | 周期 |
| `summary` | 总结 |
| `plan` | 下阶段计划 |
| `metrics` | 关键指标 JSON |
| `submitted_at` | 提交时间 |
| `status` | draft / submitted / reviewed |

### WorkReportItem（明细项）

| 字段 | 说明 |
|------|------|
| `report_id` | 报告 |
| `content` | 内容 |
| `category` | 分类（客户跟进/产品学习等） |

## 操作步骤

### 1. 提交日报

**接口**：`crm_work_report.Create`

```json
{
  "type": "daily",
  "period_start": "2026-08-18",
  "period_end": "2026-08-18",
  "summary": "今日新增客户 5 个，跟进 10 个",
  "plan": "明日重点跟进 A 类客户",
  "metrics": {
    "new_customers": 5,
    "followups": 10,
    "orders": 1
  },
  "items": [
    {"content": "拜访客户 X，需求确认", "category": "客户跟进"},
    {"content": "学习产品 Y 新功能", "category": "产品学习"}
  ]
}
```

### 2. 提交周报/月报

类似日报，但 `period_start/period_end` 跨周/月。

### 3. 主管批阅

**接口**：`work_report.Review`

```json
{
  "report_id": "100",
  "comment": "本周表现良好"
}
```

### 4. 报告统计

**接口**：`work_report.Stats(tenantID, staffID, dateRange)`

返回：
- 提交次数
- 准时率
- 平均指标

## 自动填充指标（**产品补强点**）

**当前未实现**：理想情况下，日报中的 `metrics` 应自动从 CRM 同步：

```
new_customers → count(CrmCustomer WHERE owner=? AND created_at=today)
followups → count(CrmFollowup WHERE staff=? AND created_at=today)
```

## 注意事项

- **周期对齐**：日报=1 天，周报=周一-周日，月报=本月 1 号-月末。
- **必填**：总结 + 计划必填。
- **跨租户禁止**。

## 当前限制（**产品补强点**）

- 无自动汇总（日报统计自动填充）。
- 无报告模板（行业模板/岗位模板）。
- 无报告评论/点赞。
