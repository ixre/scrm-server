# 考勤请假

## 目的
员工考勤打卡 + 请假/出差申请。

## 入口
- 工作台 → 办公协同 → 考勤打卡
- 工作台 → 办公协同 → 我的请假

## 数据模型

### Attendance（考勤记录）

| 字段 | 说明 |
|------|------|
| `staff_id` | 员工 |
| `date` | 考勤日期 |
| `clock_in_at` | 上班打卡时间 |
| `clock_out_at` | 下班打卡时间 |
| `status` | normal / late / early / absent |
| `duration_minutes` | 工时（分钟） |

### Leave（请假）

| 字段 | 说明 |
|------|------|
| `staff_id` | 申请人 |
| `type` | leave / sick / personal / annual / business |
| `start_at` / `end_at` | 请假时间 |
| `days` | 请假天数 |
| `reason` | 原因 |
| `status` | pending / approved / rejected |

## 操作步骤

### 1. 上班打卡

**接口**：`attendance.ClockIn`

```json
{
  "location": {"lat": 31.23, "lng": 121.47},
  "address": "上海市浦东新区..."
}
```

**校验**：

```go
1. 校验是否在打卡范围内（公司地址 + 半径）
2. 校验是否重复打卡（同一天仅一次）
3. 创建/更新 Attendance
4. 校验是否迟到（clock_in_at > 09:00）
```

### 2. 下班打卡

**接口**：`attendance.ClockOut`

### 3. 提交请假

**接口**：`leave.Submit`

```json
{
  "type": "annual",
  "start_at": "2026-08-20",
  "end_at": "2026-08-22",
  "reason": "家庭旅行"
}
```

**自动触发**：`approval.Submit(biz_type=leave)` 走审批流。

### 4. 审批请假

**接口**：`approval.Approve / Reject`

通过后：
- 状态置 approved
- 占用年假余额
- 工作日自动标 leave

### 5. 月度统计

**接口**：`attendance.MonthlyReport(staffID, year, month)`

返回：
- 出勤天数
- 迟到次数
- 请假天数
- 加班时长

## 与企微集成

**打卡**：通过企微打卡回调自动同步考勤记录（**当前未实现**）。

**请假**：通过企微审批回调同步审批状态。

## 注意事项

- **时区**：默认 tenant 时区，跨时区员工需特殊处理（**当前未实现**）。
- **节假日**：法定节假日自动不算出勤（**当前未对接节假日 API**）。
- **迟到判定**：按上班时间 ± 弹性区间判定，**可在系统设置调整**。

## 当前限制（**产品补强点**）

- 无弹性工作制。
- 无跨天班次（夜班）。
- 无外勤打卡特殊处理。
